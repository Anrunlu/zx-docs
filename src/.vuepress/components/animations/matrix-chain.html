矩阵连乘

区间动态规划 · 按长度填表 · 切分表恢复最优括号

题目与输入

给定按固定顺序相乘的 n 个矩阵（维度列表长度 n+1）， 只通过改变括号调整计算顺序，求最少标量乘法次数，并给出一种完全加括号方案。
维度 p = [p₀, p₁, …, pₙ] 表示第 i 个矩阵是 p[i-1] × p[i]。

输入2到9个正整数（1到8个矩阵），每个维度为1到10000，用逗号或空格分隔。

核心思路

dp[i][j]：按原顺序计算 Aᵢ…Aⱼ 的最少标量乘法次数。
dp[i][j] = mini≤k<j { dp[i][k] + dp[k+1][j] + p[i-1]·p[k]·p[j] }
左链内部成本 右链内部成本 最后一次相乘成本  ·  单矩阵时 dp[i][i] = 0
按区间长度从 2 到 n 递增填表，保证依赖的更短区间已经求出。
split[i][j] = 取得最小值的切分点 k  →  据此恢复最优括号

求解过程

维度链 p
矩阵

成本表 dp[i][j]

切分表 split[i][j]

正在计算的区间 [i, j] 左链 dp[i][k] 右链 dp[k+1][j]

易错点提示

  • 矩阵数量是 len(p) - 1：[10,30,5,60] 表示 3 个矩阵，不是 4 个。
  • 不能排序或交换矩阵：只允许改变括号，顺序必须保持不变。
  • 单矩阵成本为 0：dp[i][i] = 0，不是元素个数。
  • 不能只比较最后一次相乘：还要加上左右子链各自的最优内部成本。
  • 维度下标是 p[i-1]·p[k]·p[j]：不是 p[i]·p[k]·p[j]，左链的行数是 p[i-1]。
  • 切分点范围是 i ≤ k < j：取 k = j 会让右子链为空。
  • 必须按区间长度递增填表：随意按行填可能读到尚未计算的短区间。
  • 不要用固定的"足够大"常量当初值：最优成本可能超过它，用 None 更安全。
  • 只求最优值不等于能恢复方案：要同步保存 split[i][j]。
  • 二维表 ≠ 平方时间：每个区间还要枚举切分点，总时间是 O(n³)。
