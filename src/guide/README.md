# 新生指南

欢迎加入网络空间安全学院。


## 建议阅读顺序

1. [2026 开学报告](talks/2026-开学报告.md)：现场主线，约 15–20 分钟。
2. [四年规划](四年规划.md)：大一到大四怎么走。
3. [实践案例](实践案例.md)：用真实项目说明「实践」长什么样。

需要把某一项技术看清楚时，再进 [专题](topics/README.md)。课程讲义仍在 [教学文档](../teachbook/README.md)。

## 宣讲主线

**AI 赋能成长，实践定义未来。**

- 大学不是终点，专业前景好不等于个人前途好。
- 先立住自律、规划、执行。
- 用 AI 当助手，用项目把知识变成能力。
- 四年有路线图：基础 → 项目与比赛 → 成果 → 就业或升学。
