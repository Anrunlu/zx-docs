# 实践案例

用一组真实项目说明开学报告里的那句话：实践把知识变成能力。本页先记「做什么、学到什么」；界面截图后续上传七牛云再补。

项目名称和归属若有出入，按定稿时的口径改表，不必改报告主线。

## 案例一览

| 案例（暂用可见名称） | 大致在做什么 | 主要收获 | 细节 |
| --- | --- | --- | --- |
| 守护曲园（健康填报 / 检测查询） | 校园场景下的填报、查询与管理 | 安全、并发、前端、后台 | 待补截图与简介 |
| 外语教学数据数字化平台 | 教学与管理侧的业务系统 | 复杂业务逻辑 | 待补 |
| 业务平台深化 | 同一类系统上的复杂组件与流程 | 更复杂的业务、多种组件 | 待补正式项目名 |
| 地图类应用 | 把地理信息嵌进业务 | 地图的使用 | 待补 |
| 定位与数字大屏 | 实时位置与汇总展示 | 用户实时定位、数字大屏 | 待补 |
| 面向更多用户的产品 | 从内部工具走到真实使用 | 更多人的信任 | 待补正式项目名 |
| QFEduChat 等学业指导应用 | 用大模型回答培养方案、课程等问题 | 把 LLMs 引入已有业务 | [大模型](topics/大模型.md) |
| 小程序 | 端上交付与发布 | 小程序开发 | [小程序与工程实践](topics/小程序与工程实践.md) |
| 科研落地 | 把研究结果接到可运行系统 | 科研成果应用到项目中 | 待补对应课题名 |
| 第三方接口 | 与外部服务对接 | 接口交互与联调 | 待补 |

## 阅读建议

新生不必在开学第一周读懂每张表。先看「主要收获」列：四年里你大概率会按这个顺序碰到问题——先做出能跑的系统，再处理复杂业务，再碰到位置、大屏、大模型和对外接口。

智能体如何嵌进这些项目，不在本页展开，见 [智能体](topics/智能体.md)。
