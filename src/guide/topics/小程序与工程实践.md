# 小程序与工程实践

> 专题撰写中。对应实践案例「主要收获：小程序开发」。配图、小程序入口后续以七牛云或正式链接补入，本页不放本地图片。

开学报告里只把小程序当作一种交付方式：东西要能被真实用户打开。本篇以后写工程侧，而不是某一家平台的操作手册。

## 本篇后续会写

- 为什么很多校园和文旅项目最后要做到小程序或移动端。
- 和 Web 后台相比，端上多出来的约束：发布、权限、接口、版本。
- 和大模型、智能体专题的关系：模型在云侧，端上往往是入口。
