## 常见大模型

大模型是**大语言模型**（LLM）的简称。

## 一、国外比较有名的大模型

| 公司/机构          | 大模型            | 代表产品/系列        | 主要特点                    |
| -------------- | -------------- | -------------- | ----------------------- |
| **OpenAI**     | GPT 系列         | ChatGPT        | 综合能力强，推理、代码、多模态能力突出     |
| **Google**     | Gemini 系列      | Gemini         | 多模态能力强，与 Google 生态结合紧密  |
| **Anthropic**  | Claude 系列      | Claude         | 长文本、代码、复杂任务表现突出         |
| **Meta**       | Llama 系列       | Llama          | 开源/开放权重生态影响力大，适合科研和私有部署 |
| **xAI**        | Grok 系列        | Grok           | 实时信息、推理和社交平台生态结合        |
| **Mistral AI** | Mistral 系列     | Mistral        | 欧洲代表性模型，开源和高效模型较有影响力    |
| **Cohere**     | Command 系列     | Command        | 企业级 NLP、RAG 和知识库应用      |
| **Amazon**     | Nova / Titan 等 | Amazon Bedrock | 面向企业和云计算场景              |
| **Microsoft**  | Phi 系列         | Phi            | 小模型、端侧部署和高性价比方向         |

其中，如果只让学生记住几个，我会建议：

> **GPT、Gemini、Claude、Llama、Grok**

这几个基本可以代表当前国际大模型的重要技术路线。

## 三、如果从“技术路线”来理解，会更清楚

其实不用把几十个模型全部背下来，可以把它们理解成下面几类：

### ① 通用型“大脑”

例如：

**GPT、Gemini、Claude、Qwen、DeepSeek、GLM**

主要解决：

> “什么都能干。”

写文章、分析数据、数学推理、写代码、回答问题、处理文件等。

---

### ② 推理型大模型

代表：

**OpenAI 推理模型、DeepSeek、Qwen 推理系列、Claude 等**

重点解决：

> “这个问题很复杂，你先想清楚，再给答案。”

例如数学题、科研问题、代码 Debug、复杂决策等。

---

### ③ 开源/开放权重模型

代表：

**Llama、Qwen、DeepSeek、GLM、Mistral**

这类模型对于**高校科研尤其重要**。

因为研究人员可以：

* 下载模型
* 本地部署
* 微调
* 蒸馏
* 做 RAG
* 做 Agent
* 修改模型架构
* 进行实验

所以如果你是在给**计算机专业研究生讲大模型**，这一类尤其值得重点介绍。

---

### ④ 多模态大模型

例如：

**GPT、Gemini、Qwen、豆包、Claude 等**

已经不只是“文字 → 文字”，而是：

> **文字 + 图片 + 音频 + 视频 → 理解/生成**

比如给模型一张孔庙建筑照片，可以让它识别建筑结构、解释文化信息，再结合知识库生成讲解词。

这其实和你之前关注的**知识图谱 + RAG + 文旅/儒家文化**方向非常容易结合。
