# 最大子数组和

<Badge text="中等" type="tip" /> <Badge text="线性动态规划" type="tip" /> <Badge text="Python" type="tip" />

**遇到负数不一定要停止：为什么 `[4, -1, 2, 1]` 整段相加反而能得到最大和6？**

::: tip 本节学习目标
- **会建模：** 定义必须以当前位置结尾的最大和，保证选出的元素连续。
- **会追踪：** 区分当前结尾状态与历史最优值，判断接上前段还是重新开始。
- **会核对：** 检查全负数、单元素与空输入约定，并比较动态规划和分治摘要的成本。

前置知识：列表、循环、累加与 `max`；可先阅读[打家劫舍](./打家劫舍.md)比较两种一维状态。
:::

## 题目描述

给定整数列表 `nums`，找出一个和最大的**非空连续子数组**，返回它的元素和。子数组必须由原列表中连续的一段组成，不能跳过其中的元素，也不能通过排序改变顺序。

本题对应常见的最大子数组和问题。设列表长度为 $n$，题目范围为：

$$
1\leq n\leq10^5,\qquad -10^4\leq nums[i]\leq10^4.
$$

### 参数、结果与补充约定

- 列表下标从0开始，子数组可以包含单个元素，也可以是整个列表。
- 返回最大和，不要求返回子数组端点、元素列表或全部最优子数组；多个子数组同样最优时返回相同的数值即可。
- 输入可以含负数、0和重复值，不修改原列表。
- 为便于独立调用，本文所有函数额外约定：输入 `[]` 时返回0。它不属于上面的非空题目范围，也不表示非空列表可以选择空子数组。
- 主实现使用动态规划状态表，补充滚动变量版本；进阶用分治法返回四项摘要，求同一个最大和。

### 贯穿示例

```text
输入： [-2, 1, -3, 4, -1, 2, 1, -5, 4]
输出： 6
说明： 下标3到6的 [4, -1, 2, 1] 的和最大。

输入： [5, 4, -1, 7, 8]
输出： 23
说明： 整个列表就是一个最优子数组。

输入： [-8, -3, -6]
输出： -3
说明： 必须非空，不能返回0。
```

## 题目分析

::: tip 核心结论
只保存“以当前位置结尾”的最大和，才能合法接上下一项。当前状态等于“只取当前元素”与“前一个结尾状态加当前元素”的较大者；最终答案是所有结尾状态的最大值。
:::

### 从枚举端点到固定结尾

可以枚举左端点，再逐步扩展右端点并累加，得到 $O(n^2)$ 的解法；若每一对端点都重新对整个切片求和，还会增加重复扫描，不能仍直接按平方级分析。

为了避免枚举全部端点，先固定右端点。以位置 $i$ 结尾的连续子数组，要么只有 `nums[i]`，要么是在某个以位置 $i-1$ 结尾的非空子数组后接上 `nums[i]`。

不能直接使用“前缀中出现过的最大和”来延伸。对 `[-5, 4, -1, 2]`，处理最后的2之前，前缀最大和为4；直接加2得到6，相当于跳过 -1，破坏连续性。合法最优值为5。

### 定义结尾状态、边界与转移

定义 `dp[i]`：**必须以 `nums[i]` 结尾的非空连续子数组的最大和。**

边界为：

$$
dp[0]=nums[0].
$$

对 $i\geq1$：

$$
dp[i]=\max\bigl(nums[i],\ dp[i-1]+nums[i]\bigr).
$$

| 选择 | 对应的子数组形状 | 候选值 |
| --- | --- | --- |
| 重新开始 | 只包含当前元素 | `nums[i]` |
| 接上前段 | 以i−1结尾的最优非空连续段，再接当前元素 | `dp[i - 1] + nums[i]` |

如果 `dp[i - 1] < 0`，接上前段会降低和，从当前元素开始更好；若前一结尾状态为0，两种选择的和相同，只求最大和时不必区分。

### 当前状态不一定是最终答案

`dp[i]` 要求包含当前位置，但全局最优子数组可能已经在前面结束。因此还要维护 `max_sum`，表示到目前为止出现过的最大结尾状态：

$$
B(0)=dp[0],\qquad B(i)=\max\bigl(B(i-1),dp[i]\bigr).
$$

最终答案为 $B(n-1)=\max_{0\leq i<n}dp[i]$，不能只返回 `dp[n - 1]`。

与[打家劫舍](./打家劫舍.md)相比：那里的前缀状态不要求选择当前房屋，可以直接作为该前缀的答案；这里的结尾状态必须包含当前位置，需要再取历史最大值。相似的数组下标不代表相同的状态含义。

### 为什么只保留最大的结尾状态就足够

对于长度至少为2、以 $i$ 结尾的子数组，去掉当前元素后，一定得到一个以 $i-1$ 结尾的非空连续子数组；反过来，任意这样的前段都可以合法接上当前元素。

所有前段候选都增加同一个 `nums[i]`，大小关系不会改变，因此只需保留其中最大的 `dp[i - 1]`。再与只取当前元素的情况比较，就覆盖了全部合法选择。

初始状态正确，转移保持正确；所有非空连续子数组都有某个结尾位置，所以再对全部结尾状态取最大值，就得到整体最优解。

### 滚动变量与分治摘要

转移只依赖前一个结尾状态，可以用 `current_sum` 保存它，用 `max_sum` 保存历史最优。先更新结尾和，再更新全局最大值，时间仍为线性，额外空间可以降到常数级。

进阶分治将非空区间按位置分成两半。整体最优子数组只可能完全在左侧、完全在右侧或跨越分界。为常数时间合并，每个子调用返回四项摘要：

| 摘要 | 含义 |
| --- | --- |
| `total` | 整个区间的元素和 |
| `prefix` | 必须从区间首元素开始的最大非空前缀和 |
| `suffix` | 必须到区间末元素结束的最大非空后缀和 |
| `best` | 区间内最大非空子数组和 |

设左右摘要分别带下标 $L$、$R$，合并关系为：

$$
\begin{aligned}
\mathrm{total}&=\mathrm{total}_L+\mathrm{total}_R,\\
\mathrm{prefix}&=\max(\mathrm{prefix}_L,\ \mathrm{total}_L+\mathrm{prefix}_R),\\
\mathrm{suffix}&=\max(\mathrm{suffix}_R,\ \mathrm{total}_R+\mathrm{suffix}_L),\\
\mathrm{best}&=\max(\mathrm{best}_L,\ \mathrm{best}_R,\ \mathrm{suffix}_L+\mathrm{prefix}_R).
\end{aligned}
$$

单元素区间四项值都等于该元素，包括它为负数的情况。前缀若跨界，必须取完整左段；后缀若跨界，必须取完整右段；跨界子数组由左侧后缀与右侧前缀组成。这些条件保证合并保持连续且非空。

## 实现代码

### Python 状态表实现

保留函数名 `maxSubArray`。以下完整程序展示各位置的结尾最优值如何被计算，并独立核对主示例与边界结果。

```python{7,8,11,12}
def maxSubArray(nums):
    """返回最大非空连续子数组和；空输入额外约定返回0。"""
    if not nums:
        return 0

    dp = [0] * len(nums)
    dp[0] = nums[0]
    max_sum = dp[0]

    for i in range(1, len(nums)):
        dp[i] = max(nums[i], dp[i - 1] + nums[i])
        max_sum = max(max_sum, dp[i])

    return max_sum


if __name__ == "__main__":
    cases = [
        [-2, 1, -3, 4, -1, 2, 1, -5, 4],
        [1],
        [5, 4, -1, 7, 8],
        [-8, -3, -6],
        [-1],
        [0, 0],
        [],
    ]
    for nums in cases:
        print(f"{nums} -> {maxSubArray(nums)}")
```

输出：

```text
[-2, 1, -3, 4, -1, 2, 1, -5, 4] -> 6
[1] -> 1
[5, 4, -1, 7, 8] -> 23
[-8, -3, -6] -> -3
[-1] -> -1
[0, 0] -> 0
[] -> 0
```

非空输入的两个初始状态都来自第一个元素，不能用0代替 `max_sum`。`dp` 中其余位置的初始0只是预留空间，读取前一状态时，它已经被正确计算。

### Python 滚动变量实现

下面是空间优化后的完整程序，与状态表版本求解同一任务，不覆盖主实现的函数名。

```python{6,8,9}
def max_subarray_rolling(nums):
    """仅保存当前结尾和与历史最优，空输入返回0。"""
    if not nums:
        return 0

    current_sum = max_sum = nums[0]
    for i in range(1, len(nums)):
        current_sum = max(nums[i], current_sum + nums[i])
        max_sum = max(max_sum, current_sum)

    return max_sum


if __name__ == "__main__":
    cases = [[-5, 4, -1, 2], [-8, -3, -6], [1], []]
    for nums in cases:
        print(f"{nums} -> {max_subarray_rolling(nums)}")
```

输出：

```text
[-5, 4, -1, 2] -> 5
[-8, -3, -6] -> -3
[1] -> 1
[] -> 0
```

`current_sum` 不是“前面出现过的最大和”，它始终表示以本轮位置结尾的最大和。两版都按下标读取列表，没有通过 `nums[1:]` 创建额外切片。

### Python 进阶实现：分治返回四项摘要

这一版本按半开区间 `[lo, hi)` 划分，使用下标传递子问题，不复制左右子列表。它同样只返回最大和，不返回端点。

```python{12,13,15,16,17,18}
def max_subarray_divide(nums):
    """用总和、前缀、后缀与最优值四项摘要完成分治。"""
    if not nums:
        return 0

    def solve(lo, hi):
        if hi - lo == 1:
            value = nums[lo]
            return value, value, value, value

        mid = (lo + hi) // 2
        l_total, l_prefix, l_suffix, l_best = solve(lo, mid)
        r_total, r_prefix, r_suffix, r_best = solve(mid, hi)

        total = l_total + r_total
        prefix = max(l_prefix, l_total + r_prefix)
        suffix = max(r_suffix, r_total + l_suffix)
        best = max(l_best, r_best, l_suffix + r_prefix)
        return total, prefix, suffix, best

    return solve(0, len(nums))[3]


if __name__ == "__main__":
    cases = [[4, -1, 2, 1], [-8, -3, -6], [-1], []]
    for nums in cases:
        print(f"{nums} -> {max_subarray_divide(nums)}")
```

输出：

```text
[4, -1, 2, 1] -> 6
[-8, -3, -6] -> -3
[-1] -> -1
[] -> 0
```

四项摘要都对应非空区间。空输入在最外层单独处理，不用“空区间的0”参与非空子数组的比较，避免全负数时返回错误结果。

## 算法执行过程

### 观察任务

| 阶段 | 观察任务 |
| --- | --- |
| 扫描前 | 标出主示例中的连续段，说明为什么不能只挑选正数 |
| 逐步计算 | 每轮比较“当前元素”与“前一个结尾状态加当前元素”，再更新历史最优 |
| 结束时 | 核对最后的结尾状态与最终答案是否相同 |
| 进阶合并 | 用左右的最大后缀、最大前缀检查跨界答案，核对全负数初始化 |

### 状态表：结尾最优与历史最优同步变化

输入为 `[-2, 1, -3, 4, -1, 2, 1, -5, 4]`，初始 `dp[0] = max_sum = -2`。下表中的值均为处理完当前位置后的结果：

| 下标 $i$ | `nums[i]` | 结尾状态 `dp[i]` | 历史最优 `max_sum` | 本轮结尾状态的来源 |
| --- | ---: | ---: | ---: | --- |
| 0 | -2 | -2 | -2 | 初始化为首元素 |
| 1 | 1 | 1 | 1 | 重新开始，1大于 `-2 + 1` |
| 2 | -3 | -2 | 1 | 接上前段，`1 - 3 = -2` |
| 3 | 4 | 4 | 4 | 重新开始，4大于 `-2 + 4` |
| 4 | -1 | 3 | 4 | 接上前段，`4 - 1 = 3` |
| 5 | 2 | 5 | 5 | 接上前段，`3 + 2 = 5` |
| 6 | 1 | 6 | 6 | 接上前段，`5 + 1 = 6` |
| 7 | -5 | 1 | 6 | 接上前段，`6 - 5 = 1` |
| 8 | 4 | 5 | 6 | 接上前段，`1 + 4 = 5` |

最大值6在下标6处已经出现，对应下标3到6的 `[4, -1, 2, 1]`。结束时 `dp[8] = 5`，但历史最优仍为6，所以不能只返回最后的结尾状态。

对滚动版本，把表中的 `dp[i]` 换成 `current_sum` 即可，数值与更新顺序不变。

### 全负数：重新开始仍然必须选择一个元素

对 `[-8, -3, -6]`：

| 下标 | 当前结尾最大和 | 历史最优 |
| --- | ---: | ---: |
| 0 | -8 | -8 |
| 1 | `max(-3, -8 - 3) = -3` | -3 |
| 2 | `max(-6, -3 - 6) = -6` | -3 |

答案为 -3，而不是0。首元素初始化让后续比较始终在合法的非空候选中进行；遇到负数并不意味着可以把全局答案直接改成0。

### 分治摘要：用跨界候选得到6

主示例的根调用按中点4分为 `[0, 4)` 与 `[4, 9)`：

| 区间 | 元素 | `total` | `prefix` | `suffix` | `best` |
| --- | --- | ---: | ---: | ---: | ---: |
| 左侧 `[0, 4)` | `[-2, 1, -3, 4]` | 0 | 0 | 4 | 4 |
| 右侧 `[4, 9)` | `[-1, 2, 1, -5, 4]` | 1 | 2 | 4 | 4 |
| 整体 `[0, 9)` | 原列表 | 1 | 2 | 5 | 6 |

跨界候选为 `l_suffix + r_prefix = 4 + 2 = 6`，实际由左侧后缀 `[4]` 与右侧前缀 `[-1, 2, 1]` 连起来得到。左侧的最大前缀和0来自一个非空前缀，不是空前缀。

左右各自的最优值都是4，若只返回这两个最优值而不返回前后缀信息，就无法完整判断跨界候选。这与[最长公共前缀](../递推和分治/最长公共前缀.md)一样，需要先设计足够支持合并的摘要。

## 复杂度分析

### 先看结论

设元素数量为 $n$，按整数加法、比较、下标访问与固定长度元组操作为单位成本。表中非空输入的结论针对 $n\geq1$，空输入单独返回，时间与辅助空间均为 $O(1)$。

| 实现或任务 | 时间复杂度 | 辅助空间复杂度 | 主要开销 |
| --- | --- | --- | --- |
| 枚举左端点并逐步累加右端点 | $O(n^2)$ | $O(1)$ | 作为分析对照，不是本文主实现 |
| 状态表动态规划 | $O(n)$ | $O(n)$ | 保存所有结尾状态 |
| 滚动变量动态规划 | $O(n)$ | $O(1)$ | 保存当前结尾和与历史最优 |
| 四项摘要分治 | $O(n)$ | $O(\log(n+1))$ | 每次常数时间合并，空间来自递归栈与沿途摘要 |

辅助空间不包含原列表。本文仅求最大和；如果改为枚举全部最优子数组，需要单独计入输出量。

### 时间复杂度

两版动态规划每个位置只处理一次，每轮常数次加法与比较，状态表初始化也为线性时间，因此时间均为 $O(n)$。

四项摘要分治按位置均分，不在合并时重新扫描区间。对长度为 $n\geq2$ 的区间：

$$
T(n)=T(\lfloor n/2\rfloor)+T(\lceil n/2\rceil)+O(1).
$$

非空输入对应 $n$ 个单元素叶子与 $n-1$ 个合并节点，总工作为 $O(n)$。

如果另一种分治实现每层重新扫描求左右的最大后缀与前缀，则合并成本为 $O(n)$，总时间为 $O(n\log n)$。不能把这一结论套到本文常数时间合并的实现上。

### 辅助空间复杂度

状态表保存 $n$ 个值，占 $O(n)$；滚动版本只维护固定数量的变量，占 $O(1)$。它们都使用循环，不需要递归栈。

分治调用深度为 $O(\log(n+1))$。同一时刻只沿一条调用链展开，并保留该路径上的固定大小摘要；左右调用顺序执行，不会同时保留整棵调用树，所以辅助空间为对数级。使用下标区间避免了子列表切片的存储。

## 易错点

| 易错点 | 正确理解 |
| --- | --- |
| 先排序，或跳过所有负数再求和 | 会改变连续性，`[4, -1, 2, 1]` 的最大和为6，不是7 |
| 把结尾状态理解为前缀全局最优 | 当前状态必须包含当前位置，全局最优另外维护 |
| 直接把历史最优加上当前元素 | 历史最优可能在更早位置结束，例如 `[-5, 4, -1, 2]` 会因此误算为6 |
| 看到负数就立即丢弃当前段 | 应看前一个结尾状态的总和是否有利，而不是只看当前元素正负 |
| 将非空输入的全局答案初始化为0 | 全负数会错误地返回0，应初始化为首元素 |
| 返回最后的结尾状态 | 最大子数组可能在前面结束，应返回所有结尾状态的最大值 |
| 认为函数对空列表返回0，就允许非空输入选空段 | 空输入是额外调用约定，非空输入仍须选择至少一个元素 |
| 分治只返回左右最大子数组和 | 会遗漏跨界候选，还需要左右后缀、前缀等信息 |
| 分治叶子的前后缀初始化为0 | 会混入空段，单元素四项摘要都应等于该元素 |
| 使用切片却仍直接声称只有对数空间 | 本文分治通过下标传递区间，复制子列表需要另计空间 |

### 基础核对

**1.** 对 `[7]`、`[-7]`、`[0, 0]` 和 `[]`，本文函数分别返回多少？哪些属于非空题目范围？

分别返回7、-7、0、0。前三个是非空输入；`[]` 的0来自函数的额外约定。`[-7]` 不能选择空段得到0。
:::

**2.** “前缀中最大子数组和”与“必须以当前位置结尾的最大和”有什么区别？为什么主示例最后一个结尾状态为5，而答案为6？

::: details 参考答案
前者可以在前缀内任意位置结束，后者必须包含当前位置。主示例的最优段在下标6结束，后面的元素没有让最终结尾状态超过它，所以需要保存历史最优6。
:::

### 过程推演

**3.** 对 `[-5, 4, -1, 2]` 列出每个结尾状态和历史最优，给出一个最大子数组。

::: details 参考答案
结尾状态为 `[-5, 4, 3, 5]`，历史最优为 `[-5, 4, 4, 5]`。下标1到3的 `[4, -1, 2]` 最大，和为5。直接使用历史最优4加最后的2会跳过 -1，因此6不是合法答案。
:::

**4.** 用分治摘要合并 `[4, -1]` 与 `[2, 1]`，分别写出左右四项摘要和整体四项摘要。

::: details 参考答案
摘要顺序为 `(total, prefix, suffix, best)`。

左侧为 `(3, 4, 3, 4)`，右侧为 `(3, 3, 3, 3)`，整体为 `(6, 6, 6, 6)`。跨界候选为左后缀3加右前缀3，得到6。
:::

### 进阶思考

**5.** 前一个结尾状态为0时，接上前段与从当前元素重新开始会得到相同的和。如果只返回最大和，需要记录选了哪种方式吗？若要返回端点，还应补充什么？

::: details 参考答案
只返回最大和时不需要区分。若要返回端点，应跟踪当前候选的起点，并在更新全局最优时记录对应的起止下标；还需约定并列时取较短段、较早起点或其他规则。不能直接由一个最大和值唯一确定端点。
:::

**6.** 为什么“四项摘要分治是线性时间”与“扫描跨界部分的分治是线性对数时间”并不矛盾？

::: details 参考答案
两者的合并方式不同。前者的子调用已提供总和与最优前后缀，当前层常数时间合并；后者还要扫描当前区间来求跨界部分，合并为线性时间。递推式中的额外工作不同，因此总复杂度不同。
:::
