# 使用最小花费爬楼梯

<Badge text="简单" type="tip" /> <Badge text="线性DP" type="tip" /> <Badge text="Python" type="tip" />

**`cost = [10, 15, 20]` 的答案为什么是 15，而不是先付更便宜的 10？**

::: tip 本节学习目标
- **会建模：** 说清 `dp[i]` 表示到达第 i 阶的最小花费，并解释费用在离开时支付。
- **会追踪：** 按主示例填出完整的 dp 表，并还原一条最优路径。
- **会核对：** 区分两套等价状态定义，验证起点、终点与复杂度。

前置知识：爬楼梯计数，可先阅读[爬楼梯](./爬楼梯.md)；本课讲义见[2026年秋第7次课](../2026年秋第7次课.md)。
:::

## 题目描述

给你一个整数数组 `cost`，其中 `cost[i]` 是**从第 i 个台阶向上爬时需要支付的费用**。一旦支付，可以选择向上爬 1 个或 2 个台阶。

可以从下标为 0 或下标为 1 的台阶开始爬楼梯，开始时不需要付费。请计算并返回达到楼梯顶部的最低花费。

约束：$2\leq n\leq 1000$，$n$ 是 `cost` 的长度，$1\leq cost[i]\leq 999$。**楼梯顶部的下标是 $n$**，不是 $n-1$。

示例 1：输入 `cost = [10, 15, 20]`，输出 `15`。从下标 1 起步，支付 15 后一次爬 2 阶到顶。

示例 2：输入 `cost = [1, 100, 1, 1, 1, 100, 1, 1, 100, 1]`，输出 `6`。

### 贯穿示例

全文共用示例 2：

```text
cost = [1, 100, 1, 1, 1, 100, 1, 1, 100, 1]
n = 10，顶部下标为 10
正确输出：6
```

关注三点：顶部下标是 10；起点 0 和 1 都不付费；第 1、5、8 阶费用很高，最优方案必须绕开它们。

## 题目分析

### 从题意到方法

到达顶部 $n$ 的最后一步只有两种可能：从 $n-1$ 阶支付 $cost[n-1]$ 爬 1 阶，或从 $n-2$ 阶支付 $cost[n-2]$ 爬 2 阶。把「到达第 i 阶」看成子问题，就得到最优子结构：到达 $i$ 的最小花费，只取决于到达 $i-1$ 与 $i-2$ 的最小花费。

::: tip 核心结论
定义 $dp[i]$ 为**到达第 i 阶、尚未支付 cost[i]** 的最小花费，则

$$
dp[i]=\min\bigl(dp[i-1]+cost[i-1],\ dp[i-2]+cost[i-2]\bigr),\qquad dp[0]=dp[1]=0,
$$

答案为 $dp[n]$。适用前提是每步只能前进 1 或 2 阶、不能停留或回头，因此状态之间可以排成一条无环的线性顺序。
:::

若直接按这个式子写递归，`dp[i-1]` 与 `dp[i-2]` 会反复展开同一批状态，时间是指数级；自底向上填表让每个状态只计算一次。这正是第4次课快速幂「复用子问题结果」的同一个道理。

### 定义任务与处理边界

- $dp[0]=dp[1]=0$：题目允许从下标 0 或 1 起步，站在起点不付费，也不能把 $cost[0]$、$cost[1]$ 当作初值。
- $i$ 从 2 递增到 $n$：计算 $dp[i]$ 时 $dp[i-1]$、$dp[i-2]$ 都已就绪。
- $n=2$ 时循环只执行 $i=2$ 一次，不需要另写特判；但题目约定 $n\geq2$，因此不讨论长度为 1 的输入。

### 两套等价状态定义

另一种常见写法是令 $f[i]$ 表示**到达第 i 阶且已支付 cost[i]** 的最小花费：

$$
f[i]=cost[i]+\min(f[i-1],f[i-2]),\qquad f[0]=cost[0],\ f[1]=cost[1],
$$

答案为 $\min(f[n-1],f[n-2])$。

两套定义互为反向，都正确。差别只在于 $dp[i]$ 不含 $cost[i]$、答案取 $dp[n]$；$f[i]$ 含 $cost[i]$、答案取最后两项的较小者。**把第一套判定为"错误设计"，或把第一套的转移配上第二套的答案，都是错的**。选一套写到底，并在代码注释里写明状态含义。

### 为什么结果正确

对 $i$ 归纳。$i=0,1$ 时起点不付费，值为 0，成立。设对所有小于 $i$ 的位置成立，则任意到达 $i$ 的合法方案，最后一步必来自 $i-1$ 或 $i-2$；前段费用不低于 $dp[i-1]$ 或 $dp[i-2]$，最后一步分别支付 $cost[i-1]$ 或 $cost[i-2]$。因此任何方案的费用不低于上式右端；而取较小者对应的方案确实可达，故等号成立。$i=n$ 即为到达顶部的最低花费。

### 为什么贪心不成立

`cost = [10, 15, 20]` 中，从 0 阶起步先付 10 比从 1 阶起步付 15 便宜，但沿这条路还要付 $cost[2]=20$，总计 30；从 1 阶起步付 15 一次跨两阶到顶，总计 15。局部最省的一步不能决定全局最优，所以必须同时保留两种来路再取较小值。

## 实现代码

### Python 主实现

```python
def min_cost_climbing_stairs(cost):
    """dp[i]: 到达第 i 阶、尚未支付 cost[i] 的最小花费。"""
    n = len(cost)
    dp = [0] * (n + 1)
    for i in range(2, n + 1):
        dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2])
    return dp[n], dp


def min_cost_climbing_stairs_o1(cost):
    """只保留 dp[i-2] 与 dp[i-1]，辅助空间 O(1)。"""
    prev2 = 0
    prev1 = 0
    for i in range(2, len(cost) + 1):
        cur = min(prev1 + cost[i - 1], prev2 + cost[i - 2])
        prev2, prev1 = prev1, cur
    return prev1


if __name__ == "__main__":
    examples = [
        [10, 15, 20],
        [1, 100, 1, 1, 1, 100, 1, 1, 100, 1],
        [1, 2],
        [5, 10],
    ]
    for cost in examples:
        answer, _ = min_cost_climbing_stairs(cost)
        print(cost, "->", answer, "| o(1):", min_cost_climbing_stairs_o1(cost))
    _, table = min_cost_climbing_stairs(examples[1])
    print("dp:", table)
```

运行输出：

```text
[10, 15, 20] -> 15 | o(1): 15
[1, 100, 1, 1, 1, 100, 1, 1, 100, 1] -> 6 | o(1): 6
[1, 2] -> 1 | o(1): 1
[5, 10] -> 5 | o(1): 5
dp: [0, 0, 1, 2, 2, 3, 3, 4, 4, 5, 6]
```

注意 `prev2, prev1 = prev1, cur` 是同时赋值；若拆成两条语句先更新 `prev2`，计算时用到的就已不是旧的 `dp[i-2]`。

## 算法执行过程

对贯穿示例逐个填表，`来源` 列给出取得最小值的前驱：

| i | $dp[i-1]+cost[i-1]$ | $dp[i-2]+cost[i-2]$ | dp[i] | 来源 |
| ---: | ---: | ---: | ---: | --- |
| 0 | — | — | 0 | 起点 |
| 1 | — | — | 0 | 起点 |
| 2 | $0+100=100$ | $0+1=1$ | 1 | 从 0 爬 2 阶 |
| 3 | $1+1=2$ | $0+100=100$ | 2 | 从 2 爬 1 阶 |
| 4 | $2+1=3$ | $1+1=2$ | 2 | 从 2 爬 2 阶 |
| 5 | $2+1=3$ | $2+1=3$ | 3 | 从 3 或 4 均可 |
| 6 | $3+100=103$ | $2+1=3$ | 3 | 从 4 爬 2 阶 |
| 7 | $3+1=4$ | $3+100=103$ | 4 | 从 6 爬 1 阶 |
| 8 | $4+1=5$ | $3+1=4$ | 4 | 从 6 爬 2 阶 |
| 9 | $4+100=104$ | $4+1=5$ | 5 | 从 7 爬 2 阶 |
| 10 | $5+1=6$ | $4+100=104$ | **6** | 从 9 爬 1 阶 |

从 $dp[10]$ 反向追踪来源，得到一条最优路径：

$$
0\to2\to4\to6\to7\to9\to10,
$$

依次支付 $1+1+1+1+1+1=6$，与官方示例一致。三次费用为 100 的台阶全部被跳过。

## 复杂度分析

### 先看结论

| 实现或任务 | 时间复杂度 | 辅助空间复杂度 | 计数模型 |
| --- | --- | --- | --- |
| 数组版填表 | $O(n)$ | $O(n)$ | 一次加法、比较为常数时间 |
| 滚动变量版 | $O(n)$ | $O(1)$ | 同上，不含输入数组 |
| 朴素递归（不记忆化） | $O(2^n)$ | $O(n)$ 递归栈 | 同上 |

数组版共计算 $n+1$ 个状态，每个状态做常数次加法、比较和赋值，故时间为 $O(n)$、辅助空间为 $O(n)$。滚动变量版只保留两个前驱，辅助空间降到 $O(1)$。

朴素递归满足 $T(n)=T(n-1)+T(n-2)+O(1)$，展开后为 $O(2^n)$：同一个 $dp[i]$ 被不同分支重复计算。记忆化搜索或自底向上填表把状态数压到 $O(n)$。

这里的 $n$ 是台阶数。若还需要输出完整路径，需额外记录每个状态的前驱，空间回到 $O(n)$，输出本身也是 $O(n)$。

## 易错点

| 错误想法或写法 | 反例或后果 | 正确处理 |
| --- | --- | --- |
| 认为站在第 i 阶就付 `cost[i]` | `[10,15,20]` 会算成 25 | 只在**离开**第 i 阶时支付 |
| 在 $dp[i]$ 定义下返回 $\min(dp[n-1],dp[n-2])$ | `[10,15,20]` 得到 $\min(10,0)=0$ | 该定义下答案取 $dp[n]$；$\min(f[n-1],f[n-2])$ 属于另一套定义 |
| 把 $dp[i]=\min(dp[i-1]+cost[i-1],dp[i-2]+cost[i-2])$ 判为错误设计 | 两套等价定义被互相否定 | 先固定状态含义，再配转移与答案 |
| 令 $dp[0]=cost[0]$、$dp[1]=cost[1]$ | 起点被重复计费，贯穿示例答案会变大 | 起点不付费，$dp[0]=dp[1]=0$ |
| 每步选当前最便宜的台阶（贪心） | `[10,15,20]` 得到 30 | 保留两种来路，用 `min` 转移 |
| 分两条语句先写 `prev2 = prev1` 再算 `prev1` | 旧 `dp[i-2]` 被覆盖，结果偏大 | 用元组同时赋值，或先用临时变量保存 `cur` |
| 把顶部下标当成 $n-1$ | `[10,15,20]` 会返回 $dp[2]=10$ | 顶部下标是 $n$ |

## 课堂练习

### 基础核对

**1.** 求 `cost = [1, 2, 3]` 的最低花费，并写出一条达到该值的路线。

::: details 参考答案
$dp[0]=dp[1]=0$，$dp[2]=\min(0+2,0+1)=1$，$dp[3]=\min(1+3,0+2)=2$。答案是 2：从下标 1 起步，支付 `cost[1]=2` 后一次爬 2 阶到顶。
:::

**2.** `cost = [5, 10]` 时答案是多少？需要为长度 2 单独写特判吗？

::: details 参考答案
答案是 5：从下标 0 起步付 5 爬 2 阶到顶，$dp[2]=\min(0+10,0+5)=5$。不需要特判，循环从 $i=2$ 开始正好执行一次。
:::

### 过程推演

**3.** 按第二套定义 $f[i]=cost[i]+\min(f[i-1],f[i-2])$ 写出贯穿示例的 $f$ 表，并说明答案如何取。

::: details 参考答案
$f[0]=1$，$f[1]=100$，$f[2]=1+\min(100,1)=2$，$f[3]=3$，$f[4]=3$，$f[5]=4$，$f[6]=103$，$f[7]=5$，$f[8]=6$，$f[9]=105$。完整表为 `[1, 100, 2, 3, 3, 4, 103, 5, 6, 105]`。答案取 $\min(f[9],f[8])=\min(105,6)=6$，与 $dp[10]=6$ 一致。
:::

**4.** 从 $dp[10]$ 反向追踪贯穿示例的来源，写出最优路径与各步支付的费用。

::: details 参考答案
路径为 $0\to2\to4\to6\to7\to9\to10$，对应支付 `cost[0]=1`、`cost[2]=1`、`cost[4]=1`、`cost[6]=1`、`cost[7]=1`、`cost[9]=1`，合计 6。注意 $i=5$ 时两个前驱同为 3，可选不同路径但总费用不变。
:::

### 进阶思考

**5.** 若 `cost` 中出现 0 或负数，上述转移是否仍然成立？

::: details 参考答案
仍然成立。正确性只依赖「每步必须前进 1 或 2 阶、状态可按 i 排成无环顺序」，与费用正负无关；`min` 在负数下照常比较。因为不能停留或回头，也无法通过反复踩同一个负费用台阶无限降低成本。若题目改为允许停留或来回移动，状态图出现环，就需要重新建图并用最短路等方法。
:::

**6.** 若每次可以爬 1、2、3 阶，转移方程和边界要怎么改？

::: details 参考答案
$i\geq3$ 时增加第三项：$dp[i]=\min(dp[i-1]+cost[i-1],\ dp[i-2]+cost[i-2],\ dp[i-3]+cost[i-3])$。若仍只允许从下标 0 或 1 起步，则 $dp[0]=dp[1]=0$，$dp[2]$ 仍按原来的两项转移计算，不能把 $dp[2]$ 也置为 0；时间仍为 $O(n)$，滚动变量需要保留 3 个前驱，辅助空间仍为 $O(1)$。
:::
