# 打家劫舍

<Badge text="基础" type="tip" /> <Badge text="线性动态规划" type="tip" /> <Badge text="Python" type="tip" />

**房屋金额为 `[2, 7, 9, 3, 1]`，相邻房屋不能同时选择，怎样一步步算出最大金额12？**

::: tip 本节学习目标
- **会建模：** 用“前i间房屋的最大金额”定义状态，从选或不选当前房屋推导转移。
- **会追踪：** 按顺序填写状态表，再用两个滚动变量复现同一过程。
- **会核对：** 区分房屋编号与列表下标，检查空输入、首尾关系与变量更新顺序。

前置知识：列表、下标、循环与 `max`；课堂串联可阅读[2026年秋第6次课](../2026年秋第6次课.md)。
:::

## 题目描述

沿一条直线排列着若干间房屋，每间房屋存放一定金额。选择任意两间相邻房屋会触发报警，因此要求相邻房屋不能同时选择。在这一约束下，求能够选择的最大总金额。

可以将题意抽象为：给定一个非负整数列表 `nums`，从中选择若干个互不相邻的位置，使对应元素之和最大，返回这个最大值。

### 参数、结果与编号规则

- 输入参数 `nums` 为非负整数列表，长度记为 $n$；可以为空，也可以含0或重复金额。输入按这些约束保证有效。
- 返回一个整数，表示最大总金额；允许一个位置也不选，所以空列表与全零列表都返回0。
- 不修改输入列表，本题只要求最优金额，不要求返回房屋编号或枚举全部方案。
- 房屋按从左到右编号为1到 $n$，第 $i$ 间对应 `nums[i - 1]`；Python 列表下标从0开始。
- 相邻指房屋编号相差1。房屋沿直线排列，当 $n\geq3$ 时首间与末间不相邻；当 $n=2$ 时，两间房屋仍然相邻。

### 贯穿示例

```text
输入： [2, 7, 9, 3, 1]
输出： 12
说明： 选择第1、3、5间，金额为 2 + 9 + 1 = 12。

输入： [1, 2, 3, 1]
输出： 4
说明： 选择第1、3间，金额为 1 + 3 = 4。

输入： [2, 1, 1, 2]
输出： 4
说明： 选择第1、4间；直线排列中的这两间不相邻。
```

::: warning 明确直线模型
若首尾也相邻，题目就变成环形扩展，合法方案会发生变化。例如 `[2, 1, 1, 2]` 的环形答案为3，直线答案为4。本文两种 Python 实现均解决直线模型。
:::

## 题目分析

::: tip 核心结论
当前房屋只有“选”和“不选”两种情况。不选时继承前i−1间的最优值；选择时，跳过相邻的前一间，与前i−2间的最优值相加。比较两个候选，得到前i间的最优值。
:::

### 从枚举方案到保存前缀最优值

直接尝试每间房屋选或不选，再筛除相邻位置同时选择的情况，可以求出答案，但朴素枚举需要考虑至多 $2^n$ 个选择组合。

局部选择也不能代替整体比较。例如 `[2, 3, 2]` 中，先选金额最大的中间房屋只能得到3，而选两端可以得到4。

需要保存的是：当问题缩小为“只考虑前若干间房屋”时，能够达到的最优金额。这样处理当前房屋时，就能复用已经求出的前缀结果。

### 定义状态与边界

定义 `dp[i]`：**只考虑前 $i$ 间房屋，在不同时选择相邻房屋的条件下，能够获得的最大金额。**

这里的 $i$ 表示房屋数量，`dp[i]` 不要求一定选择第 $i$ 间。第 $i$ 间房屋的金额是 `nums[i - 1]`，不是 `nums[i]`。

边界为：

$$
dp[0]=0,\qquad dp[1]=nums[0]\quad(n\geq1).
$$

`dp[0]` 对应空前缀。对于非空列表，因为金额非负，只有一间房屋时最大金额就是它的金额；空列表在访问 `nums[0]` 之前直接返回0。

使用长度为 $n+1$ 的状态表，最终答案为 `dp[n]`。

### 根据是否选择当前房屋推导转移

对于 $i\geq2$，所有合法方案可以分成互不重叠的两类：

| 当前选择 | 为什么可以使用较小状态 | 本类最优值 |
| --- | --- | --- |
| 不选第 $i$ 间 | 决策完全落在前 $i-1$ 间之内 | `dp[i - 1]` |
| 选择第 $i$ 间 | 第 $i-1$ 间不能选，前 $i-2$ 间的任意合法方案都能与当前房屋搭配 | `dp[i - 2] + nums[i - 1]` |

取二者最大值，得到：

$$
dp[i]=\max\bigl(dp[i-1],\ dp[i-2]+nums[i-1]\bigr),\qquad 2\leq i\leq n.
$$

注意，“选择当前房屋”不意味着必须选择第 $i-2$ 间。`dp[i - 2]` 可以来自前 $i-2$ 间中的任意合法选择，所以算法允许跳过多间房屋，也允许最优方案同时包含奇数与偶数编号。

### 为什么只保留最优金额就足够

若选择第 $i$ 间，前 $i-2$ 间的选择与它之间已经隔开一间房屋。无论此前选了哪些位置，只要此前合法，就可以与当前房屋搭配。

因此，这部分方案中金额较小的结果可以被最优结果替换，而不破坏合法性。不选当前房屋时同理，只需使用前 $i-1$ 间的最优结果。当前转移无需知道每个历史方案的具体位置。

边界正确，且两类选择覆盖所有合法方案。假设较小前缀的状态都正确，上述转移就能得到当前前缀的最优值；按 $i$ 从小到大计算，最终 `dp[n]` 正确。

### 从重叠子问题到滚动变量

如果直接递归计算同一递推式，求 `dp[5]` 需要 `dp[4]` 与 `dp[3]`，求 `dp[4]` 时又会用到 `dp[3]`，从而重复计算相同前缀。

可以使用记忆化递归，在计算前查询缓存；本文采用自底向上的循环，按依赖顺序计算每个状态，避免重复求解，也不使用递归栈。

计算新状态只需读取前两个状态，因此还可以进一步用两个变量代替整个状态表：

- 处理第 $i$ 间前，`prev2` 保存 `dp[i - 2]`，`prev1` 保存 `dp[i - 1]`。
- 先计算 `current = max(prev1, prev2 + nums[i - 1])`。
- 再更新为 `prev2 = 旧prev1`、`prev1 = current`，供下一轮使用。

先用状态表理解含义，再做空间优化；不能先覆盖旧状态，再计算还需要它的新状态。

## 实现代码

### Python 状态表实现

`rob(nums)` 返回直线模型的最大金额。以下程序可以完整复制到 Python 文件中运行，输出与题目示例一致。

```python{7,8,11,12,13,15}
def rob(nums):
    """返回非相邻房屋的最大总金额，不修改输入列表。"""
    n = len(nums)
    if n == 0:
        return 0

    dp = [0] * (n + 1)
    dp[1] = nums[0]

    for i in range(2, n + 1):
        skip = dp[i - 1]
        take = dp[i - 2] + nums[i - 1]
        dp[i] = max(skip, take)

    return dp[n]


if __name__ == "__main__":
    cases = [
        [2, 7, 9, 3, 1],
        [1, 2, 3, 1],
        [2, 1, 1, 2],
        [],
        [7],
        [0, 0, 0],
    ]
    for nums in cases:
        print(f"{nums} -> {rob(nums)}")
```

输出：

```text
[2, 7, 9, 3, 1] -> 12
[1, 2, 3, 1] -> 4
[2, 1, 1, 2] -> 4
[] -> 0
[7] -> 7
[0, 0, 0] -> 0
```

状态表的下标范围为0到 $n$，而金额列表的下标范围为0到 $n-1$。循环中的 `i` 是当前处理的房屋编号，读取金额时要减1。

### Python 滚动变量实现

下面保留相同的输入约定、状态边界与转移，仅减少保存的状态。该程序也可以独立运行。

```python{6,7,10,11}
def rob_rolling(nums):
    """只保存前两个前缀最优值，返回最大总金额。"""
    if not nums:
        return 0

    prev2 = 0          # dp[0]
    prev1 = nums[0]    # dp[1]

    for i in range(2, len(nums) + 1):
        current = max(prev1, prev2 + nums[i - 1])
        prev2, prev1 = prev1, current

    return prev1


if __name__ == "__main__":
    cases = [[2, 7, 9, 3, 1], [2, 1, 1, 2], [], [7]]
    for nums in cases:
        print(f"{nums} -> {rob_rolling(nums)}")
```

输出：

```text
[2, 7, 9, 3, 1] -> 12
[2, 1, 1, 2] -> 4
[] -> 0
[7] -> 7
```

Python 多变量赋值先计算右侧，所以 `prev2, prev1 = prev1, current` 使用的是旧 `prev1` 与已经计算好的新状态。两版都不创建输入切片、不排序、不修改原列表。

## 算法执行过程

### 观察任务

| 阶段 | 观察任务 |
| --- | --- |
| 计算前 | 标出房屋编号与金额下标，预测哪些房屋可以同时选择 |
| 逐步填表 | 每轮分别写出“选”和“不选”的候选，说明为什么选择第i间时使用前i−2间的最优值 |
| 核对结果 | 检查主示例得到12，再用首尾都适合选择的例子区分直线与环形 |
| 优化空间 | 对照同一张状态表，追踪两个旧变量怎样移动，避免覆盖依赖 |

### 状态表：从空前缀计算到完整列表

输入为 `[2, 7, 9, 3, 1]`。先初始化 `dp[0] = 0`、`dp[1] = 2`，再按主实现处理第2到第5间：

| 房屋数量 $i$ | 当前金额 `nums[i - 1]` | 不选：`dp[i - 1]` | 选择：`dp[i - 2] + nums[i - 1]` | 本轮得到 `dp[i]` |
| --- | ---: | ---: | --- | ---: |
| 0 | — | — | — | 0 |
| 1 | 2 | — | 初始化单房屋状态 | 2 |
| 2 | 7 | 2 | `0 + 7 = 7` | 7 |
| 3 | 9 | 7 | `2 + 9 = 11` | 11 |
| 4 | 3 | 11 | `7 + 3 = 10` | 11 |
| 5 | 1 | 11 | `11 + 1 = 12` | 12 |

最终状态表为 `[0, 2, 7, 11, 11, 12]`，返回 `dp[5] = 12`。

处理第4间后，最优金额仍为11，说明不必选择最新的房屋。处理第5间时，使用的是前3间的最优值11，再加第5间的1；中间的第4间不选，因此仍然合法。

### 人工核对一组最优选择

状态表只保存最优金额，并没有直接返回房屋编号。课堂上可从最后一个状态反向核对：

| 当前前缀 | 对比状态 | 一种最优选择的核对方式 |
| --- | --- | --- |
| 前5间 | `dp[5] = 12 > dp[4] = 11` | 选择第5间，跳过第4间，转到前3间 |
| 前3间 | `dp[3] = 11 > dp[2] = 7` | 选择第3间，跳过第2间，转到前1间 |
| 前1间 | 金额为2 | 选择第1间 |

得到第1、3、5间，金额为 $2+9+1=12$。这里只核对一种合法最优选择；若候选相等，可能存在多个最优方案。两版主函数仍然只返回金额，不输出上述反向过程。

### 滚动变量：保留同一转移需要的两个旧值

初始为 `prev2 = 0`、`prev1 = 2`。下表记录每轮计算前的旧值，以及本轮更新后的变量：

| 房屋编号 $i$ | 当前金额 | 旧 `prev2` | 旧 `prev1` | 新状态 `current` | 更新后 `(prev2, prev1)` |
| --- | ---: | ---: | ---: | --- | --- |
| 2 | 7 | 0 | 2 | `max(2, 0 + 7) = 7` | `(2, 7)` |
| 3 | 9 | 2 | 7 | `max(7, 2 + 9) = 11` | `(7, 11)` |
| 4 | 3 | 7 | 11 | `max(11, 7 + 3) = 11` | `(11, 11)` |
| 5 | 1 | 11 | 11 | `max(11, 11 + 1) = 12` | `(11, 12)` |

最后返回 `prev1 = 12`。压缩后不再保留完整历史表，适合本题仅求最大金额的任务；若要恢复房屋编号方案，需要另行设计并保存足够的信息。

### 边界与反例：检查模型是否一致

| 输入或检查方式 | 正确结果或结论 | 检查重点 |
| --- | --- | --- |
| `[]` | 0 | 访问 `nums[0]` 前先处理空输入 |
| `[7]` | 7 | 初始化后直接返回 |
| `[2, 7]` | 7 | 两间相邻，只能选一间或都不选 |
| `[0, 0, 0]` | 0 | 零金额合法，不要求必须选择房屋 |
| `[2, 3, 2]` | 4 | 先选全局最大金额可能失去整体最优解 |
| `[2, 1, 1, 2]` | 4 | 首尾可以同时选；只按奇偶分组各得3，会漏掉最优方案 |

与[最大子数组和](./最大子数组和.md)比较：本题的 `dp[i]` 不要求选择第 $i$ 间；最大子数组和中的结尾状态则必须包含当前位置。看到相似的一维数组写法，也要先核对状态含义。

## 复杂度分析

### 先看结论

设房屋数为 $n$，按整数读取、加法、赋值与比较为单位成本。表中复杂度针对 $n\geq1$，空输入直接返回，时间与辅助空间均为 $O(1)$。

| 实现或任务 | 时间复杂度 | 辅助空间复杂度 | 保存的主要信息 |
| --- | --- | --- | --- |
| 状态表实现 `rob` | $O(n)$ | $O(n)$ | `n + 1` 个前缀最优值 |
| 滚动变量实现 `rob_rolling` | $O(n)$ | $O(1)$ | 前两个状态及本轮候选 |

辅助空间均不包含输入列表。若金额大到需要考虑 Python 大整数的位数，加法与比较的实际成本也随整数长度变化；上表采用课程中的单位运算模型。

### 时间复杂度

状态表初始化需要 $O(n)$ 时间，随后每个前缀状态只计算一次，每轮只做常数次读取、加法和比较，因此总时间为 $O(n)$。

滚动变量版本省去了状态表，但仍需读取各房屋金额，时间仍为 $O(n)$。空间优化改变的是保存的信息数量，没有减少需要处理的房屋数量。

普通递归会重复求解相同前缀；若没有记忆化，不能因为状态只有 $n+1$ 个，就直接判断其运行时间也是线性级。本文两版循环实现均按依赖顺序复用已求出的结果。

### 辅助空间复杂度

`rob` 创建长度为 $n+1$ 的状态表，占 $O(n)$ 辅助空间；`rob_rolling` 只保存固定数量的变量，占 $O(1)$ 辅助空间。两版均使用循环，没有递归栈。

示例中的输入列表本身占 $O(n)$ 存储，不属于额外创建的状态表。若讨论完整程序的总存储，需要把输入也计入。

## 易错点

| 易错点 | 正确理解 |
| --- | --- |
| 说 `dp[i]` 是前i间的最优金额，却读取 `nums[i]` | 前i间的最后一间是 `nums[i - 1]`，注意数量与下标的偏移 |
| 将 `dp[i]` 理解为必须选择第i间 | 它只限制考虑的范围，可以不选当前房屋 |
| 选择当前房屋时加上 `dp[i - 1]` | 可能包含相邻的前一间，应加 `dp[i - 2]` |
| 认为只能选全部奇数编号或全部偶数编号 | `[2, 1, 1, 2]` 的最优方案同时选择第1、4间 |
| 先选金额最大的房屋，再排除相邻房屋 | `[2, 3, 2]` 会错选3，最优值实际为4 |
| 直接读取 `nums[0]` 后才判断是否为空 | 空列表会越界，必须先处理空输入 |
| 将直线题目拆成去首、去尾两种情况 | 这是处理环形首尾冲突的方式，会排除本题部分合法方案 |
| 先覆盖 `prev2`，再计算新状态 | 可能把前一间的最优值误当成前两间之前的状态，导致相邻房屋被同时选 |
| 返回状态表中的房屋数量，而不是状态值 | 应返回 `dp[n]`；滚动实现返回 `prev1` |
| 认为状态表直接保存了选择方案 | 表中只存金额，恢复具体编号需要额外的反向核对或决策记录 |
| 认为两个变量就能让时间变为常数级 | 每间房屋仍需处理一次，时间为线性级 |

## 课堂练习

先独立作答，再逐题展开答案核对。

### 基础核对

**1.** 对 `[]`、`[0]`、`[8]`、`[8, 3]` 和 `[0, 0, 0]`，最大金额分别是多少？

::: details 参考答案
分别为0、0、8、8、0。允许不选任何房屋；两间房屋相邻，不能把8与3同时相加。
:::

**2.** `dp[3]` 在本文中表示什么？读取第3间的金额时应使用哪个 Python 下标？主示例的 `dp[4] = 11` 是否意味着一定选择第4间？

::: details 参考答案
`dp[3]` 表示前3间中、不同时选择相邻房屋时的最大金额；第3间对应 `nums[2]`。`dp[4] = 11` 不要求选择第4间，主示例中这一最优值由第1、3间达到。
:::

### 过程推演

**3.** 对 `[4, 1, 1, 4]` 列出完整状态表，给出一组最优房屋编号，并核对是否符合相邻约束。

::: details 参考答案
状态表为 `[0, 4, 4, 5, 8]`，最终返回8。选择第1、4间，两者编号差为3，在线性排列中不相邻。

只选奇数编号或只选偶数编号都只能得到5，说明固定按奇偶分组不足以覆盖所有合法方案。
:::

**4.** 对 `[2, 1]`，滚动实现处理第2间之前的变量是什么？若先写 `prev2 = prev1`，再计算 `max(prev1, prev2 + 1)`，会得到什么错误结果？

::: details 参考答案
正确的旧变量是 `prev2 = 0`、`prev1 = 2`，所以新状态为 `max(2, 0 + 1) = 2`，更新后的变量为 `(2, 2)`。

若先把 `prev2` 覆盖为2，就会得到3，相当于把两间相邻房屋同时选中。应先用旧状态求出新值，再更新变量。
:::

### 进阶思考

**5.** `[2, 1, 1, 2]` 的直线答案与环形答案分别是多少？若确实要研究环形扩展，为什么可以在至少两间房屋时比较“去掉末间”和“去掉首间”的两个线性子问题？

::: details 参考答案
直线答案为4，环形答案为3。

环形中首尾不能同时选择，因此每个合法方案至少排除首间或末间之一。两段线性子问题的合法方案合起来覆盖所有环形合法方案，取较大值即可；这不要求被保留的端点必须选中。单房屋情况要单独处理，不能直接把它删掉后返回0。

本文主实现没有这一首尾冲突，应直接求整个线性列表的最优金额。
:::

**6.** 对 `[2, 2]`，状态转移的两个候选相等。只返回最大金额时，是否必须记录选择了哪一间？如果要输出一种最优方案，能否直接使用滚动变量的最后两个值确定全部编号？

::: details 参考答案
只求金额时不必区分，两个方案的最优值都是2。

如果要输出编号，仅凭最后两个滚动值不能直接恢复全部历史决策；可保留完整状态表并约定候选相等时的处理方式，再反向恢复一种方案。若要求全部最优方案，还需考虑可能很大的输出数量，不能直接沿用仅求金额的时间与空间结论。
:::
