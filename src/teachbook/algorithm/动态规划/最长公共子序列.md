# 最长公共子序列

<Badge text="中等" type="tip" /> <Badge text="二维动态规划" type="tip" /> <Badge text="Python" type="tip" />

**`"abcde"` 与 `"ace"` 的最长公共子序列是 `"ace"`，长度 3；为什么 `"aec"` 不算，状态表又是怎样一格一格填出 3 的？**

::: tip 本节学习目标
- **会建模：** 用“两个字符串前缀的最长公共子序列长度”定义二维状态，从末字符是否相等推导两类转移。
- **会追踪：** 按主示例填写完整状态表，用两行滚动数组复现同一过程，并从表尾反向恢复一种具体子序列。
- **会核对：** 区分前缀下标与字符下标、子序列与子串、只求长度与输出方案，检查空串与重复字符。

前置知识：字符串下标、列表推导式与嵌套循环；一维状态可对照[打家劫舍](./打家劫舍.md)，状态分类见[动态规划的分类](./动态规划的分类.md)。
:::

## 题目描述

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的**最长公共子序列**的长度；如果不存在公共子序列，返回 0。

一个字符串的**子序列**是由原字符串在不改变字符相对顺序的前提下，删除某些字符（也可以一个都不删）后得到的新字符串。例如 `"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是。两个字符串的**公共子序列**是二者共同拥有的子序列。

### 参数、结果与编号规则

- 输入 `text1`、`text2` 为字符串，长度分别记为 $m$、$n$，题目约定 $1\le m,n\le1000$，且只由小写英文字符组成。
- 返回一个整数，即最长公共子序列的长度；不要求返回具体子序列，也不修改输入字符串。
- 子序列**不要求连续**，只要求相对顺序一致；允许一个字符都不选，空串与任意串的最长公共子序列长度为 0。
- 字符串按 Python 习惯从 0 开始下标：`text1` 的第 $i$ 个字符是 `text1[i - 1]`。状态表多开一行一列，`dp[i][j]` 对应 `text1[:i]` 与 `text2[:j]`。
- 最长公共子序列可以不止一种；长度是唯一的，具体方案不是。

::: warning 名字相近，问题不同
[最长公共前缀](../递推和分治/最长公共前缀.md)求的是多个字符串**从开头起连续相同**的一段；本题求的是**可不连续、保持顺序**的最长公共子序列，两者不是同一类问题。
:::

### 贯穿示例

```text
输入： text1 = "abcde", text2 = "ace"
输出： 3
说明： 最长公共子序列是 "ace"，长度为 3。

输入： text1 = "abc", text2 = "abc"
输出： 3
说明： 最长公共子序列是 "abc"。

输入： text1 = "abc", text2 = "def"
输出： 0
说明： 两个字符串没有公共子序列，返回 0。
```

全文用第一组作主示例，状态表、滚动数组与回溯都基于它。

## 题目分析

### 从枚举子序列到前缀状态

最直接的做法是枚举 `text1` 的所有子序列，再逐个检查它是否也是 `text2` 的子序列。`text1` 有至多 $2^m$ 个子序列，在 $m=1000$ 时完全不可行。

需要保存的是：当两个字符串都只看前若干个字符时，最长公共子序列能有多长。这样处理末尾字符时就能复用已经求出的、规模更小的结果。这类「双序列前缀」状态也出现在[编辑距离](./编辑距离.md)中。

### 定义状态与边界

定义 `dp[i][j]`：**`text1` 的前 $i$ 个字符 `text1[:i]` 与 `text2` 的前 $j$ 个字符 `text2[:j]` 的最长公共子序列长度。**

它不要求一定要选 `text1[i - 1]` 或 `text2[j - 1]`。正是这一点让“跳过某个字符”能被表达。

边界是任意一个前缀为空，结果都为 0，所以用一行一列哨兵统一处理：

$$
dp[0][j]=0,\qquad dp[i][0]=0.
$$

状态表大小为 $(m+1)\times(n+1)$，最终答案为 `dp[m][n]`。

### 根据末字符是否相等推导转移

对 $i,j\ge1$，比较 $s=text1[i-1]$ 与 $t=text2[j-1]$：

| 情况 | 为什么可以这样化归 | 本格取值 |
| --- | --- | --- |
| $s=t$ | 一定存在包含这个公共末字符的最优解，去掉它后问题变成两个更短前缀 | `dp[i-1][j-1] + 1` |
| $s\ne t$ | 最优解不可能同时用到这两个末字符，至少要跳过其中一个 | `max(dp[i-1][j], dp[i][j-1])` |

写成递推式：

$$
dp[i][j]=
\begin{cases}
dp[i-1][j-1]+1, & s=t,\\[4pt]
\max\bigl(dp[i-1][j],\ dp[i][j-1]\bigr), & s\ne t.
\end{cases}
$$

::: tip 核心结论
不匹配时两个跳过方向都必须考虑。`dp[i-1][j]` 表示不用 `text1[i-1]`，`dp[i][j-1]` 表示不用 `text2[j-1]`；取较大者覆盖所有可能的最优方案。
:::

反例：`text1 = "ab"`、`text2 = "cab"`，在计算 `dp[2][2]`（`"ab"` 与 `"ca"`）时末字符 `b\ne a`。此时 `dp[1][2] = 1`（公共子序列 `"a"`）、`dp[2][1] = 0`，只取后者就会把答案误算成 0；完整表格的最终答案是 2，对应 `"ab"`。

### 为什么只保留长度就足够

若末字符相等，把某个最优公共子序列的公共末字符去掉，得到的是两个更短前缀的公共子序列，长度至多 `dp[i-1][j-1]`；反过来把 `dp[i-1][j-1]` 对应的任一方案接上这个公共字符，仍是合法公共子序列。因此这一分支取 `dp[i-1][j-1]+1` 恰好正确。

若末字符不等，任何公共子序列都不可能同时以这两个字符结尾，因此必然被「跳过 `text1` 末字符」或「跳过 `text2` 末字符」之一覆盖，取两者较大即可。前缀状态已把历史选择压缩成一个长度值，不需要记录具体选了哪些位置。

边界正确、两类分支覆盖所有情况，且每个格子只依赖上方 `dp[i-1][j]`、左方 `dp[i][j-1]` 和左上方 `dp[i-1][j-1]`。按 $i$ 外层递增、$j$ 内层递增填表时，这三个值都已求出，最终 `dp[m][n]` 正确。

### 从二维表到两行滚动数组

观察依赖可以发现：计算第 $i$ 行只需要第 $i-1$ 行，以及**本行已经算出的左侧格子**。因此不必保留整张表，用 `prev`（上一行）与 `curr`（当前行）两个长度为 $n+1$ 的数组即可：

- 相等时 `curr[j] = prev[j-1] + 1`；
- 不等时 `curr[j] = max(prev[j], curr[j-1])`，注意 `curr[j-1]` 是本行的新值，不能写成 `prev[j-1]`；
- 每行算完执行 `prev, curr = curr, prev` 交换复用，返回 `prev[n]`。

因为 $j$ 从 1 到 $n$ 会把 `curr[1..n]` 全部重新赋值，复用旧数组不会残留干扰；但 `curr[0]` 必须保持 0，它是每行左侧的哨兵。

压缩空间后只得到长度。若要恢复具体子序列，仍需完整状态表或额外的决策记录。

## 实现代码

### Python 主实现

`lcs_length(text1, text2)` 返回最长公共子序列长度。以下程序可完整复制到 Python 文件中运行。

```python{4,6,7,8,9,10,11,13}
def lcs_length(text1, text2):
    """返回两个字符串的最长公共子序列长度，不修改输入。"""
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    return dp[m][n]


if __name__ == "__main__":
    cases = [
        ("abcde", "ace"),
        ("abc", "abc"),
        ("abc", "def"),
        ("", "abc"),
        ("ab", "cab"),
        ("abc", "acb"),
        ("abcbdab", "bdcaba"),
    ]
    for a, b in cases:
        print(f"({a!r}, {b!r}) -> {lcs_length(a, b)}")
```

输出：

```text
('abcde', 'ace') -> 3
('abc', 'abc') -> 3
('abc', 'def') -> 0
('', 'abc') -> 0
('ab', 'cab') -> 2
('abc', 'acb') -> 2
('abcbdab', 'bdcaba') -> 4
```

`[[0] * (n + 1) for _ in range(m + 1)]` 必须用列表推导式创建，每一行都是独立列表；写成 `[[0] * (n + 1)] * (m + 1)` 会让所有行共享同一个对象，改一格会污染整列。

### Python 滚动数组实现

下面保留相同的状态含义与转移，只把空间从 $O(mn)$ 压到 $O(n)$。该程序也可独立运行。

```python{7,10,12,13,14}
def lcs_rolling(text1, text2):
    """只保留上一行与当前行，返回最长公共子序列长度。"""
    n = len(text2)
    prev = [0] * (n + 1)
    curr = [0] * (n + 1)
    for i in range(1, len(text1) + 1):
        curr[0] = 0
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                curr[j] = prev[j - 1] + 1
            else:
                curr[j] = max(prev[j], curr[j - 1])
        prev, curr = curr, prev
    return prev[n]


if __name__ == "__main__":
    for a, b in [("abcde", "ace"), ("abc", "def"), ("abcbdab", "bdcaba")]:
        print(f"({a!r}, {b!r}) -> {lcs_rolling(a, b)}")
```

输出：

```text
('abcde', 'ace') -> 3
('abc', 'def') -> 0
('abcbdab', 'bdcaba') -> 4
```

交换后返回的是 `prev[n]` 而不是 `curr[n]`：循环末尾已把刚算完的行换到 `prev`。若想进一步减小空间，可以在开始时交换两个参数，令数组长度取 $\min(m,n)+1$；LCS 长度对两个参数是对称的，但输出的具体子序列可能不同。

### 反向恢复一种最长公共子序列

主实现只返回长度。若确实需要输出一种方案，可以保留完整状态表，再从右下角反向走：末字符相等就收录该字符并同时回退一行一列；否则朝 `dp` 值较大的方向回退。下面的约定在两者相等时优先跳过 `text1` 的末字符。

```python{14,15,16,19,20,21,23}
def lcs_one(text1, text2):
    """返回一种最长公共子序列；需要完整状态表。"""
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    chars = []
    i, j = m, n
    while i > 0 and j > 0:
        if text1[i - 1] == text2[j - 1]:
            chars.append(text1[i - 1])
            i -= 1
            j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1
    return "".join(reversed(chars))


if __name__ == "__main__":
    for a, b in [("abcde", "ace"), ("abc", "acb"), ("abc", "def")]:
        print(f"({a!r}, {b!r}) -> {lcs_one(a, b)!r}")
```

输出：

```text
('abcde', 'ace') -> 'ace'
('abc', 'acb') -> 'ab'
('abc', 'def') -> ''
```

回溯是 $O(m+n)$ 的，但完整状态表占了 $O(mn)$ 空间。这也说明空间优化与“输出方案”是两种不同的需求，不能同时只靠两行数组满足。

## 算法执行过程

### 观察任务

| 阶段 | 观察任务 |
| --- | --- |
| 计算前 | 标出两个字符串的下标，说明 `dp[i][j]` 对应哪两段前缀，并预测第 0 行与第 0 列的值 |
| 逐步填表 | 每格先判断末字符是否相等，再写出所依赖的上方、左方、左上方三个值 |
| 核对结果 | 检查 `dp[5][3] = 3`，并用 `"abc"` 与 `"def"` 核对全不相等的情况 |
| 优化与恢复 | 对照同一张表追踪两行数组如何移动，再从右下角反向读出一种子序列 |

### 主示例的完整状态表

`text1 = "abcde"`（下标 0–4），`text2 = "ace"`（下标 0–2）。行号 $i$ 表示 `text1` 的前 $i$ 个字符，列号 $j$ 表示 `text2` 的前 $j$ 个字符。

| `dp[i][j]` | $j=0$（空） | $j=1$（`a`） | $j=2$（`c`） | $j=3$（`e`） |
| --- | ---: | ---: | ---: | ---: |
| $i=0$（空） | 0 | 0 | 0 | 0 |
| $i=1$（`a`） | 0 | 1 | 1 | 1 |
| $i=2$（`b`） | 0 | 1 | 1 | 1 |
| $i=3$（`c`） | 0 | 1 | 2 | 2 |
| $i=4$（`d`） | 0 | 1 | 2 | 2 |
| $i=5$（`e`） | 0 | 1 | 2 | **3** |

最终 `dp[5][3] = 3`。第 0 行与第 0 列全为 0，对应任意一个前缀为空；`dp` 值沿行、沿列都不会下降，因为扩大前缀只会增加可选字符。

### 关键格子逐个解释

| 格子 | 比较 | 依赖的值 | 结果 |
| --- | --- | --- | ---: |
| `dp[1][1]` | `a == a` | `dp[0][0] + 1 = 0 + 1` | 1 |
| `dp[1][2]` | `a != c` | `max(dp[0][2], dp[1][1]) = max(0, 1)` | 1 |
| `dp[2][2]` | `b != c` | `max(dp[1][2], dp[2][1]) = max(1, 1)` | 1 |
| `dp[3][2]` | `c == c` | `dp[2][1] + 1 = 1 + 1` | 2 |
| `dp[3][3]` | `c != e` | `max(dp[2][3], dp[3][2]) = max(1, 2)` | 2 |
| `dp[5][3]` | `e == e` | `dp[4][2] + 1 = 2 + 1` | 3 |

注意 `dp[3][2]` 用的是 `dp[2][1]`，也就是 `"ab"` 与 `"a"` 的结果，而不是同一行左侧的 `dp[3][1]`。匹配分支跳过的是**两个字符串各一个末字符**，下标同时减 1。

`dp[5][3] = 3` 说明 `"abcde"` 与 `"ace"` 能按顺序取出 3 个公共字符，但表里只保存长度，并没有直接保存 `"ace"`。

### 反向读出一种子序列

从 $(5,3)$ 出发，相等时收录字符，不等时朝 `dp` 值较大的相邻格走：

| 当前位置 | 比较 | 决策 | 下一位置 |
| --- | --- | --- | --- |
| $(5,3)$ | `e == e` | 收录 `e` | $(4,2)$ |
| $(4,2)$ | `d != c` | `dp[3][2] = 2 >= dp[4][1] = 1`，跳过 `d` | $(3,2)$ |
| $(3,2)$ | `c == c` | 收录 `c` | $(2,1)$ |
| $(2,1)$ | `b != a` | `dp[1][1] = 1 >= dp[2][0] = 0`，跳过 `b` | $(1,1)$ |
| $(1,1)$ | `a == a` | 收录 `a` | $(0,0)$ |

把收录的字符逆序排列得到 `"ace"`。若两处候选相等时改走另一个方向，可能得到别的最长公共子序列；长度仍是 3。

### 滚动数组逐行对照

初始 `prev = [0, 0, 0, 0]`。下表每一行恰是完整状态表中对应的那一行：

| 处理的字符 | 本行 `curr`（$j=0,1,2,3$） | 与二维表的对应行 |
| --- | --- | --- |
| $i=1$（`a`） | `[0, 1, 1, 1]` | 第 1 行 |
| $i=2$（`b`） | `[0, 1, 1, 1]` | 第 2 行 |
| $i=3$（`c`） | `[0, 1, 2, 2]` | 第 3 行 |
| $i=4$（`d`） | `[0, 1, 2, 2]` | 第 4 行 |
| $i=5$（`e`） | `[0, 1, 2, 3]` | 第 5 行 |

以 $i=3$ 为例：`curr[1] = max(prev[1], curr[0]) = max(1, 0) = 1`；`curr[2]` 遇到 `c == c`，取 `prev[1] + 1 = 1 + 1 = 2`；`curr[3]` 遇到 `c != e`，取 `max(prev[3], curr[2]) = max(1, 2) = 2`。行末交换后，`prev` 变成 `[0, 1, 2, 2]`，供下一行使用。

### 边界与反例

| 输入或检查方式 | 正确结果或结论 | 检查重点 |
| --- | --- | --- |
| `("", "abc")` | 0 | 空串直接返回；第 0 行已覆盖，不必特判 |
| `("abc", "abc")` | 3 | 完全相同时每格走匹配分支 |
| `("abc", "def")` | 0 | 全表为 0，公共子序列可以是空串 |
| `("ab", "cab")` | 2 | 不匹配时必须取两个方向的较大值 |
| `("abc", "acb")` | 2 | `"ab"` 与 `"ac"` 都是最长方案，长度唯一 |
| `("abcbdab", "bdcaba")` | 4 | 经典用例；贪心挑最早匹配容易失手 |
| `("abcde", "ace")` 交换参数 | 仍为 3 | 长度对称，但回溯得到的具体方案可能不同 |
| 把转移改成不匹配时置 0 | 求的是最长公共子串 | 子序列允许跳过字符，不能断掉历史长度 |

与[矩阵连乘](./矩阵连乘.md)比较：两者都用二维状态，但矩阵连乘按**区间长度**递推、依赖同区间内更小的子区间；本题按**两个前缀的下标**递推、依赖相邻的三个格子。看到 `dp[i][j]` 先确认 $i,j$ 各代表什么，再决定填表顺序。

## 复杂度分析

设 $m=|text1|$、$n=|text2|$，以一次字符比较、一次 `max` 与一次列表读写为单位成本；题目约束下 $m,n\le1000$。

### 先看结论

| 实现或任务 | 时间复杂度 | 辅助空间复杂度 | 保存的主要信息 |
| --- | --- | --- | --- |
| 二维表 `lcs_length` | $O(mn)$ | $O(mn)$ | $(m+1)(n+1)$ 个前缀答案 |
| 滚动数组 `lcs_rolling` | $O(mn)$ | $O(n)$ | 上一行与当前行 |
| 恢复方案 `lcs_one` | $O(mn)$ | $O(mn)$ | 完整表 + 回溯用的字符列表 |
| 朴素枚举所有子序列 | $O(2^m\cdot n)$ | 视实现而定 | 枚举出的子序列 |

辅助空间不含输入字符串。若交换参数使数组按较短串建立，滚动版可写成 $O(\min(m,n))$。

### 时间复杂度

二维表有 $mn$ 个格子，每格只做常数次比较与赋值，总时间 $O(mn)$。滚动数组没有减少要计算的格子数，时间仍是 $O(mn)$；它减少的是同时保存的信息量。

`lcs_one` 先花 $O(mn)$ 建表，回溯每步至少让 $i$ 或 $j$ 减 1，至多 $m+n$ 步，不改变 $O(mn)$ 的量级。

朴素递归若不记忆化，会反复求解相同的前缀对；不能因为状态只有 $(m+1)(n+1)$ 个，就认为它的运行时间也是 $O(mn)$。

### 辅助空间复杂度

`lcs_length` 创建 $(m+1)\times(n+1)$ 的列表，占 $O(mn)$。当 $m=n=1000$ 时约为一百万个格子，题目内存限制下通常仍可接受，但这是滚动优化的动机。

`lcs_rolling` 只创建两个长度为 $n+1$ 的列表，占 $O(n)$；两版都用循环，没有递归栈。若任务改为**输出**一种最长公共子序列，仅凭最后两行无法恢复历史决策，需要 $O(mn)$ 的完整表或等价的决策记录，复杂度结论要重新给出。

## 易错点

| 易错点 | 反例或后果 | 正确处理 |
| --- | --- | --- |
| 用 `[[0] * (n + 1)] * (m + 1)` 建表 | 所有行共享同一列表，改一格影响整列 | 用列表推导式逐行创建独立列表 |
| 把比较写成 `text1[i] == text2[j]` | `i=m` 时越界，且整体错位一格 | 状态下标比字符下标大 1，比较 `text1[i-1]` 与 `text2[j-1]` |
| 不匹配时只取 `dp[i-1][j]` 或只取 `dp[i][j-1]` | `"ab"` 与 `"cab"` 的 `dp[2][2]` 会被算成 0 | 取两个跳过方向的 `max` |
| 字符不相等时仍写 `dp[i-1][j-1] + 1` | 无中生有地增加长度 | 加 1 只用于末字符相等的分支 |
| 把状态定义为“必须以两个末字符结尾” | 无法表达跳过字符，转移写不下去 | 用前缀状态 `text1[:i]` 与 `text2[:j]` |
| 把子序列当子串，遇不等就清零 | `"abcde"` 与 `"ace"` 会被算成 1 | 子序列不要求连续，不匹配时继承较大值 |
| 混淆最长公共子序列与最长公共前缀 | 两者约束完全不同 | 前缀必须连续且从开头起；子序列只保序 |
| 表格少开一行一列 | 访问 `dp[i-1][j-1]` 时下标为负或越界 | 开 $(m+1)\times(n+1)$，循环从 1 开始 |
| 认为最长公共子序列唯一 | `"abc"` 与 `"acb"` 有 `"ab"`、`"ac"` 两种 | 长度唯一；输出方案需约定相等时的走向 |
| 滚动版把 `curr[j-1]` 写成 `prev[j-1]` | 用错上一行的值，答案偏小 | 左方依赖是本行刚算出的 `curr[j-1]` |
| 滚动版交换后返回 `curr[n]` | 拿到的是尚未计算的旧行 | 循环末尾已交换，应返回 `prev[n]` |
| 认为两行数组也能直接回溯输出方案 | 历史行已丢失，无法判断往哪走 | 恢复方案需完整表或额外记录决策 |
| 认为朴素递归自动是 $O(mn)$ | 相同前缀对被重复求解，实为指数级 | 用记忆化递归或自底向上填表 |
| 交换两个输入后期待长度变化 | LCS 长度对称，交换后仍相同 | 可交换参数以缩短滚动数组；具体方案可能不同 |

## 课堂练习

先独立作答，再逐题展开答案核对。

### 基础核对

**1.** 对 `("", "abc")`、`("abc", "abc")`、`("abc", "def")`、`("abc", "acb")`，最长公共子序列长度分别是多少？最后一组的最长公共子序列唯一吗？

::: details 参考答案
依次为 0、3、0、2。

`("abc", "acb")` 的最长公共子序列不唯一：`"ab"`（取 `a`、`b`）与 `"ac"`（取 `a`、`c`）长度都是 2。题目只要求长度，这个值是唯一的 2。
:::

**2.** 主示例中的 `dp[3][2]` 表示哪两段前缀？它为什么等于 2？计算时比较的是哪两个字符？

::: details 参考答案
`dp[3][2]` 对应 `text1[:3] = "abc"` 与 `text2[:2] = "ac"`。

比较 `text1[2] = 'c'` 与 `text2[1] = 'c'`，相等，所以取 `dp[2][1] + 1 = 1 + 1 = 2`，对应公共子序列 `"ac"`。注意用的是 `text1[i-1]` 与 `text2[j-1]`，不是 `text1[i]`。
:::

### 过程推演

**3.** 对 `text1 = "ab"`、`text2 = "cab"` 写出完整状态表，并指出哪一格能证明“不匹配时只取一个方向会错”。

::: details 参考答案
状态表（行 $i=0,1,2$；列 $j=0,1,2,3$，对应空、`c`、`a`、`b`）：

| | 0 | 1 | 2 | 3 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 0 | 0 | 0 | 0 |
| 1（`a`） | 0 | 0 | 1 | 1 |
| 2（`b`） | 0 | 0 | 1 | 2 |

关键格是 `dp[2][2]`（`b != a`）：`dp[1][2] = 1`、`dp[2][1] = 0`，正确值 `max(1, 0) = 1`。若只取 `dp[i][j-1]` 一侧就会得到 0，后续 `dp[2][3]` 也会跟着算错，最终答案不再是 2。
:::

**4.** 主示例用滚动数组时，处理 $i=3$ 之前 `prev` 是什么？逐格写出本行 `curr` 的 4 个值，并说明 `curr[2]` 的来历。

::: details 参考答案
处理 $i=3$ 前，`prev` 是第 2 行 `[0, 1, 1, 1]`。

本行（`text1[2] = 'c'`）：`curr[0] = 0`；`curr[1] = max(prev[1], curr[0]) = max(1, 0) = 1`；`curr[2]` 遇到 `c == c`，取 `prev[1] + 1 = 1 + 1 = 2`；`curr[3] = max(prev[3], curr[2]) = max(1, 2) = 2`。得到 `[0, 1, 2, 2]`，与二维表第 3 行一致。

`curr[2]` 用的是**上一行**的 `prev[1]`（左上方），不是本行的 `curr[1]`；这正是匹配分支与不匹配分支的区别。
:::

### 进阶思考

**5.** 如果题目改为输出一种最长公共子序列，为什么两行滚动数组不够用？写出主示例从 $(5,3)$ 回溯到 `"ace"` 的完整决策链。

::: details 参考答案
回溯每一步都要比较 `dp[i-1][j]` 与 `dp[i][j-1]`，甚至 `dp[i-1][j-1]`，这些值分布在多行的历史状态里；两行数组只保留当前与上一行，走回更早的行时信息已被覆盖。要么保留完整 $O(mn)$ 表，要么在填表时额外记录每格的选择方向。

主示例的决策链：$(5,3)$ 处 `e == e`，收录 `e` 并转到 $(4,2)$；$(4,2)$ 处 `d != c` 且 `dp[3][2] = 2 > dp[4][1] = 1`，跳过 `d` 转到 $(3,2)$；$(3,2)$ 处 `c == c`，收录 `c` 转到 $(2,1)$；$(2,1)$ 处 `b != a` 且 `dp[1][1] = 1 > dp[2][0] = 0`，跳过 `b` 转到 $(1,1)$；$(1,1)$ 处 `a == a`，收录 `a` 后到 $(0,0)$ 结束。逆序拼接得到 `"ace"`。
:::

**6.** 若把转移改成 `dp[i][j] = dp[i-1][j-1] + 1 if 相等 else 0`，并且额外维护全表最大值，求出来的是什么？为什么本题不能这样写？

::: details 参考答案
这样求的是**最长公共子串**（必须连续）的长度，因为一旦末字符不相等就把连续段清零；全表最大值用于记录任意位置结束的最长连续段。

本题的子序列允许跳过字符：`"ace"` 相对 `"abcde"` 中间跳过了 `b`、`d`，历史长度必须被继承。`"abcde"` 与 `"ace"` 用子串写法只能得到 1，而正确的最长公共子序列长度是 3。
:::
