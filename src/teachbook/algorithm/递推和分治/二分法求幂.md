# 二分法求幂（快速幂）

<Badge text="入门" type="tip" /> <Badge text="递归与分治" type="tip" /> <Badge text="Python" type="tip" />

**同样求 $2^{13}$，怎样把12次连续乘法减少到5次？** 从“指数减半”出发，理解递归怎样在返回时构造答案。

::: tip 本节学习目标
- **会分解：** 根据指数奇偶，把求幂转化为一次半次幂求解。
- **会追踪：** 分清递归调用的顺序与结果返回的顺序。
- **会分析：** 说明为什么复用结果能减少乘法次数。

前置知识：[递归函数与调用过程](./猴子吃桃.md)、整数除法和奇偶判断。
:::

## 题目描述

给定整数底数 $a$ 和非负整数指数 $n$，求 $a^n$。要求利用指数减半的思想设计求解算法，减少乘法次数，并输出计算结果。

| 项目 | 本题约定 |
| --- | --- |
| 输入 | 整数底数 $a$、非负整数指数 $n$ |
| 输出 | $a^n$ 的精确整数结果 |
| 底数范围 | 可以为正整数、负整数或0 |
| 指数范围 | $n\geq0$，暂不处理负指数或小数指数 |
| 零次方 | 统一返回1，包括 $(a,n)=(0,0)$，与 Python 整数幂运算一致 |
| 实现要求 | 自己完成分解与合并，不直接调用 `a ** n` 或 `pow(a, n)` 得到答案 |

### 贯穿示例

本篇的代码、递归过程和动画都以 $a=2,n=13$ 为主示例：

$$
2^{13}=8192.
$$

| 输入 | 输出 | 关注点 |
| --- | ---: | --- |
| $a=2,n=13$ | 8192 | 奇数指数如何补乘 |
| $a=-2,n=5$ | $-32$ | 负底数的奇数次幂 |
| $a=7,n=0$ | 1 | 零次方边界 |

这里的“二分”指将指数规模约减半。这种方法通常称为**快速幂**或**二进制幂**。

## 题目分析

### 从连续相乘到指数减半

当 $n\geq1$ 时，直接把 $n$ 个 $a$ 连续相乘，需要 $n-1$ 次乘法。也可以写成 $a^n=a\cdot a^{n-1}$，但每次指数只减少1，求解层数仍与 $n$ 成正比。

> **先想一想：** 已经知道 $a^6$，是否还需要从头计算 $a^{12}$ 和 $a^{13}$？

利用幂的运算性质，设 $k=\lfloor n/2\rfloor$，将指数分成两种情况：

| 指数情况 | 分解关系 | 已求出 $a^k$ 后的操作 |
| --- | --- | --- |
| 偶数 $n=2k$ | $a^n=a^k\cdot a^k$ | 平方 |
| 奇数 $n=2k+1$ | $a^n=a^k\cdot a^k\cdot a$ | 平方，再补乘一个底数 |

::: tip 核心结论：半次幂只求一次
先求出 $a^k$，把结果保存在 `half` 中，再计算 `half * half`。公式里出现两次 $a^k$，表示**同一个结果使用两次**，只需一次递归调用。
:::

以 $2^{13}$ 为例：

$$
2^{13}=(2^6)^2\cdot2,\qquad
2^6=(2^3)^2,\qquad
2^3=(2^1)^2\cdot2.
$$

**分解路线：** `13 → 6 → 3 → 1`。先沿调用链到达边界，再逐层平方并按奇偶补乘。

### 定义函数、边界与递推关系

定义 `fast_power(a, n)`：返回底数 `a` 的 `n` 次方。

- **边界：** $n=0$ 返回1，$n=1$ 返回底数 $a$。
- **子问题：** 求一次 $a^{\lfloor n/2\rfloor}$。
- **合并：** 子结果平方；若当前指数为奇数，再乘 $a$。

数学上的递推关系为：

$$
F(a,n)=
\begin{cases}
1, & n=0,\\
a, & n=1,\\
F(a,n/2)^2, & n\geq2\text{ 且 }n\text{ 为偶数},\\
F(a,\lfloor n/2\rfloor)^2\cdot a, & n\geq3\text{ 且 }n\text{ 为奇数}.
\end{cases}
$$

代码使用 `n // 2` 保证指数为整数，使用 `n % 2` 判断奇偶。对于 $n\geq2$，总有 $\lfloor n/2\rfloor<n$，因此递归必然到达边界。正指数的调用链会在1处停止；0次方由单独的分支直接处理。

### 为什么结果正确

当 $n=0$ 或 $n=1$ 时，直接返回约定的正确结果。

对于更大的指数，假设子调用已正确求出 $a^k$：若 $n=2k$，平方后得到 $a^{2k}$；若 $n=2k+1$，平方后补乘 $a$，得到 $a^{2k+1}$。两个分支都恰好得到当前答案。

因此，算法的逻辑可以概括为：**指数减半 → 求解半次幂 → 平方与必要的补乘**。

## 实现代码

### Python 递归实现

以下主实现可以完整复制到 Python 文件中运行。重点阅读高亮的“子调用与合并”部分，再回看前面的输入检查和边界处理。

```python{13-18}
def fast_power(a, n):
    """用指数减半的递归方法，返回整数 a 的非负整数次幂。"""
    if type(a) is not int or type(n) is not int:
        raise TypeError("a 和 n 必须是整数")
    if n < 0:
        raise ValueError("n 必须是非负整数")

    if n == 0:
        return 1
    if n == 1:
        return a

    half = fast_power(a, n // 2)  # 相同的半次幂只求一次
    squared = half * half

    if n % 2 == 0:
        return squared
    return squared * a          # 奇数指数补乘一个底数


for a, n in [(2, 13), (3, 5), (-2, 5), (7, 0), (0, 4), (0, 0)]:
    print(f"{a} 的 {n} 次方：{fast_power(a, n)}")
```

**运行输出：**

```text
2 的 13 次方：8192
3 的 5 次方：243
-2 的 5 次方：-32
7 的 0 次方：1
0 的 4 次方：0
0 的 0 次方：1
```

读代码时，对齐下面三件事：

| 代码 | 对应含义 |
| --- | --- |
| `half = fast_power(a, n // 2)` | 等待一次子调用返回，保存半次幂 |
| `squared = half * half` | 使用同一个子结果完成平方 |
| `return squared * a` | 当前层指数为奇数，补乘原底数 |

`half` 是每层调用自己的局部变量。当前层先等待子调用返回，随后才进行合并；补乘的始终是底数 `a`。

### Python 循环实现

掌握递归后，可展开下面的补充实现，比较如何用固定数量的变量完成计算。

::: details 补充实现：从指数的二进制低位开始处理

循环版本用 `result` 累积已选中的幂，用 `base` 保存当前对应的底数幂。

```python{12-18}
def fast_power_iterative(a, n):
    """用循环完成快速幂，不保存递归调用栈。"""
    if type(a) is not int or type(n) is not int:
        raise TypeError("a 和 n 必须是整数")
    if n < 0:
        raise ValueError("n 必须是非负整数")

    result = 1
    base = a
    exponent = n

    while exponent > 0:
        if exponent % 2 == 1:
            result *= base
        exponent //= 2
        if exponent > 0:
            base *= base       # 还有下一轮时，才准备下一轮的底数幂

    return result


print(fast_power_iterative(2, 13))  # 8192
print(fast_power_iterative(-2, 5))  # -32
print(fast_power_iterative(7, 0))   # 1
```

每轮开始时，都保持关系 `result * base ** exponent == a ** n`，其中 `a` 和 `n` 是原始输入。

剩余指数为奇数时，先把一个 `base` 纳入 `result`；随后将指数减半，并在需要下一轮时把 `base` 平方。指数变成0后，`result` 就是答案。上述等式用于解释正确性，代码不会实际用它计算幂。

:::

### 递归调用：指数逐层减半

```text
fast_power(2, 13)  等待 fast_power(2, 6)
  fast_power(2, 6)  等待 fast_power(2, 3)
    fast_power(2, 3)  等待 fast_power(2, 1)
      fast_power(2, 1)  直接返回2
```

每层只有一个子调用，调用结构是一条链。沿链向下时，父调用仍在等待；真正的平方和补乘发生在返回时。

### 递归返回：平方并按奇偶补乘

| 当前指数 $n$ | `half` | 当前层计算 | 返回值 | 乘法次数 |
| --- | ---: | --- | ---: | ---: |
| 1 | — | 边界，直接返回底数2 | 2 | 0 |
| 3 | 2 | `2 * 2 * 2`，奇数补乘 | 8 | 2 |
| 6 | 8 | `8 * 8`，偶数只平方 | 64 | 1 |
| 13 | 64 | `64 * 64 * 2`，奇数补乘 | 8192 | 2 |

::: tip 核对结果
**返回值：** `2 → 8 → 64 → 8192`。

**乘法次数：** $0+2+1+2=5$；连续相乘需要 $13-1=12$ 次。

算法只求解合并答案所需的指数，没有依次计算所有的 $2^1,2^2,\ldots,2^{13}$。
:::

### 循环执行：逐位累积幂

::: details 对照循环版本的四轮状态

指数13的二进制表示为 $1101_2$，即 $13=8+4+1$，因此最终将 $2^8$、$2^4$ 和 $2^1$ 相乘。

下表的指数、底数幂、累积结果均为**本轮开始时**的状态：

| 轮次 | `exponent` | `base` | `result` | 本轮累乘 | 结束时 `result` |
| --- | ---: | ---: | ---: | --- | ---: |
| 1 | 13 | 2 | 1 | `1 * 2` | 2 |
| 2 | 6 | 4 | 2 | 偶数，不累乘 | 2 |
| 3 | 3 | 16 | 2 | `2 * 16` | 32 |
| 4 | 1 | 256 | 32 | `32 * 256` | 8192 |

四轮的 `base` 分别是 $2^1,2^2,2^4,2^8$。本例循环版本有3次底数平方和3次结果累乘，共6次乘法；具体次数与递归版本不同，但都随指数的二进制位数增长。

:::

## 复杂度分析

先采用课程常用的**单位成本模型**：一次整数乘法、整数除法和奇偶判断按常数时间计，空间按变量及调用栈帧数量计数。

### 先看结论

| 实现 | 时间复杂度 | 辅助空间复杂度 | 主要原因 |
| --- | --- | --- | --- |
| 递归快速幂 | $O(\log(n+2))$ | $O(\log(n+2))$ | 每层指数减半，保存调用栈 |
| 循环快速幂 | $O(\log(n+2))$ | $O(1)$ | 每轮指数减半，变量数量固定 |
| 朴素连续相乘 | 正指数时 $O(n)$ | $O(1)$ | 逐次累乘底数 |

### 时间复杂度

递归每层只有一次规模约减半的子调用，并进行常数次额外操作。对于 $n\geq2$：

$$
T(n)=T(\lfloor n/2\rfloor)+O(1),\qquad T(0)=T(1)=O(1).
$$

当 $n\geq1$ 时，共有 $\lfloor\log_2 n\rfloor+1$ 层调用。对于 $n\geq2$，时间为 $O(\log n)$；$n=0$ 和 $n=1$ 直接返回。统一覆盖全部非负指数时，可以写成 $O(\log(n+2))$。循环版本每轮也将剩余指数减半，得到相同时间上界。

::: warning 只计算一次半次幂，是对数级时间的关键
若写成 `fast_power(a, n // 2) * fast_power(a, n // 2)`，相同子问题会被重复求解。此时实际执行两个子调用，递推变为 $T(n)=2T(\lfloor n/2\rfloor)+O(1)$，总时间退化到 $O(n)$。
:::

### 辅助空间复杂度

递归版本保存各层参数、局部变量和返回位置，辅助空间为 $O(\log(n+2))$。循环版本维护固定数量的变量，辅助空间为 $O(1)$。

与[猴子吃桃](./猴子吃桃.md)相比，猴子吃桃每层把剩余天数减少1，快速幂每层把指数约减半，递归深度分别是线性级和对数级。

::: details 补充阅读：Python 大整数的实际成本

上述结论按算术操作次数和变量数量计算。Python 整数能增长为大整数；当 $|a|\geq2$ 时，结果 $a^n$ 的二进制位数随 $n\log_2|a|$ 增长，整数乘法不能一直按常数时间计费。

循环版本的 $O(1)$ 指变量数量固定，不表示只需要常数个二进制位。快速幂减少了乘法次数，精确结果所需的存储与输出成本仍然存在。

:::

## 易错点

### 用反例检查理解

| 错误写法或想法 | 反例或后果 | 正确处理 |
| --- | --- | --- |
| 零次方返回0 | $7^0$ 应为1 | `n == 0` 返回1；循环从 `result = 1` 开始 |
| 用 `n / 2` 递归 | 指数变成浮点数 | 使用整数除法 `n // 2` |
| 奇数指数只平方 | $2^3$ 错算为4 | 平方后补乘底数 `a` |
| 两次递归求相同半次幂 | 产生重复计算，失去对数时间 | 保存一次子调用结果并复用 |
| 写成 `a ^ n` | Python 中 `2 ^ 3` 为1 | `^` 是按位异或，本题用乘法实现幂 |
| 把平方写成 `half * 2` | `half=8` 时得到16，平方应为64 | 使用 `half * half` |
| 接受负指数 | 超出本题整数结果的输入约定 | 检查并抛出 `ValueError` |
| 循环只在偶数轮更新底数 | 奇数轮后下一轮底数幂错误 | 只要还有下一轮，就准备平方后的 `base` |

## 课堂练习

先独立作答，再逐题展开答案核对。

### 基础核对

**1. 边界与符号。** 输入 $(a,n)=(5,0),(0,6),(-2,6),(-2,5)$，分别返回什么？

::: details 参考答案

分别为1、0、64、$-32$。零次方按约定返回1；负底数的偶数次幂为正，奇数次幂为负。

:::

**2. 偶数指数。** 求 $a^{16}$ 时，调用链有哪些指数？递归版本进行几次乘法？

::: details 参考答案

调用链为 `16 → 8 → 4 → 2 → 1`。四个非边界层都只平方，共4次乘法。

:::

### 过程推演

**3. 手算递归返回。** 求 $3^5$，写出调用指数、返回值和总乘法次数。

::: details 参考答案

调用指数为 `5 → 2 → 1`；返回值为 `3 → 9 → 243`。指数2这一层做1次乘法，指数5这一层做2次乘法，共3次。

:::

**4. 对照循环版本。** 求 $2^{10}$ 时，会选择哪些底数幂纳入 `result`？

::: details 参考答案

$10=1010_2=8+2$，因此选择 $2^2=4$ 与 $2^8=256$，相乘得到1024。

:::

### 进阶思考

**5. 判断重复计算。** 为什么直接将两个 `fast_power(a, n // 2)` 相乘，会失去对数级的时间复杂度？

::: details 参考答案

两次子调用的参数完全相同，却分别执行，产生重复计算。调用结构从一条链变成二叉展开，实际工作递推变为 $T(n)=2T(\lfloor n/2\rfloor)+O(1)$，时间变为 $O(n)$。

:::
