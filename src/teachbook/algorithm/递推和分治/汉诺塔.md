# 汉诺塔

## 题目描述

有三根柱子 A、B、C。A柱上有 $n$ 个圆盘，从下到上按从大到小排列。借助B柱，把所有圆盘移动到C柱，并遵守以下规则：

1. 每次只能移动一个圆盘。
2. 只能移动某根柱子最上面的圆盘。
3. 大圆盘不能放在小圆盘上面。

约定 $n$ 是正整数。圆盘按大小编号为1到 $n$，1号最小，$n$ 号最大。要求输出完整的移动过程，并给出最少移动次数。

**示例：** 当 $n=3$ 时，最少需要7步。其中第4步是把3号圆盘从A移到C。当 $n=1$ 时，直接把1号圆盘从A移到C，只需要1步。

**进阶要求：** 给定从1开始的整数步骤编号 $m$，求最优移动方案的第 $m$ 步移动哪个圆盘、从哪根柱子移到哪根柱子，同时给出总步数。要求 $1\leq m\leq 2^n-1$。

## 题目分析

### 明确递归函数的任务

定义 `hanoi(n, source, auxiliary, target)`：借助 `auxiliary`，把 `source` 上最上面的 `n` 个圆盘合法地移到 `target`，输出移动过程，并返回移动次数。

柱子的名称固定，但“源柱、辅助柱、目标柱”是当前子问题的角色。进入子问题后，同一根柱子可能承担不同角色。

### 把大问题分为三个顺序步骤

要把最大的 $n$ 号圆盘从A移到C，必须先把上面的 $n-1$ 个圆盘移开。因此按以下顺序执行：

1. 借助C，把上面的 $n-1$ 个圆盘从A移到B。
2. 把最大的 $n$ 号圆盘从A移到C。
3. 借助A，把 $n-1$ 个圆盘从B移到C。

第1步和第3步都是规模更小的汉诺塔问题，可交给同一个函数处理，但需要调整柱子的角色：

| 当前任务 | 源柱 source | 辅助柱 auxiliary | 目标柱 target |
| --- | --- | --- | --- |
| 整体任务 | A | B | C |
| 第一次递归：把上面的圆盘移开 | A | C | B |
| 第二次递归：把上面的圆盘移到目标柱 | B | A | C |

只有一个圆盘时，直接从源柱移到目标柱并返回1。每次递归让圆盘数减1，最终会到达这个终止条件。

递归执行按程序顺序进行：**先完成第一次递归，再移动当前最大的圆盘，最后执行第二次递归。** 两次递归不会同时执行。

### 为什么方案合法且步数最少

先假设 $n-1$ 个圆盘的子问题已经能够合法完成。第1步把上面的圆盘全部移到辅助柱后，最大的圆盘就可以移到目标柱；第3步再把较小圆盘移到它上面，始终满足大盘不能放在小盘上的规则。配合单个圆盘的终止条件，可以用数学归纳法说明整个方案合法。

设移动 $n$ 个圆盘的最少步数为 $M(n)$。两个子任务各需要 $M(n-1)$ 步，中间移动最大圆盘需要1步：

$$
M(1)=1,\qquad M(n)=2M(n-1)+1.
$$

考虑任意合法方案：最大的圆盘第一次离开源柱前，其他圆盘必须全部移到另一根柱子，至少需要 $M(n-1)$ 步；它最后一次到达目标柱后，其他圆盘还要整体移到它上面，至少再需要 $M(n-1)$ 步。最大圆盘自身至少移动一次，所以任何方案都至少需要 $2M(n-1)+1$ 步。上述递归方案恰好达到这个下界。

两边加1后得到 $M(n)+1=2(M(n-1)+1)$，逐层展开可得：

$$
M(n)=2^n-1.
$$

### 怎样直接定位第 m 步

整个最优方案由“左子任务 → 移动最大圆盘 → 右子任务”构成。左子任务有 $2^{n-1}-1$ 步，因此移动最大圆盘的步骤编号为：

$$
\mathrm{middle}=2^{n-1}.
$$

- 若 $m<\mathrm{middle}$，第 $m$ 步位于左子任务，继续查询“源柱 → 辅助柱”。
- 若 $m=\mathrm{middle}$，直接回答：移动 $n$ 号圆盘，从源柱到目标柱。
- 若 $m>\mathrm{middle}$，第 $m$ 步位于右子任务，把局部步骤编号改为 $m-\mathrm{middle}$，继续查询“辅助柱 → 目标柱”。

每次只进入一个子任务，圆盘数减1。当子任务只剩一个圆盘时，有效步骤只能是1，正好命中中间步骤。

## 实现代码

### Python 递归实现：输出全部步骤

以下函数在输出移动过程的同时返回步数，不使用全局计数器。参数 `n` 约定为正整数，三根柱子的名称互不相同。

```python
def hanoi(n, source="A", auxiliary="B", target="C"):
    """输出最优移动过程，并返回移动次数。"""
    if n < 1:
        raise ValueError("n 必须是正整数")

    if n == 1:
        print(f"圆盘1：{source} → {target}")
        return 1

    # 先借助目标柱，把上面的圆盘移到辅助柱。
    left_count = hanoi(n - 1, source, target, auxiliary)

    # 上面的圆盘全部移开后，才能移动当前最大的圆盘。
    print(f"圆盘{n}：{source} → {target}")

    # 再借助原来的源柱，把上面的圆盘移到目标柱。
    right_count = hanoi(n - 1, auxiliary, source, target)

    return left_count + 1 + right_count


total = hanoi(3)
print("总移动次数：", total)
```

输出：

```text
圆盘1：A → C
圆盘2：A → B
圆盘1：C → B
圆盘3：A → C
圆盘1：B → A
圆盘2：B → C
圆盘1：A → C
总移动次数： 7
```

每层的 `left_count` 和 `right_count` 都是当前调用自己的局部变量。子任务返回后，当前层才得到对应的步数，最后返回两侧步数加上中间的1步。

### Python 进阶实现：直接查询第 m 步

第 $m$ 步从1开始计数。该函数返回 `(圆盘编号, 源柱, 目标柱)`，可以独立复制运行：

```python
def hanoi_kth_move(n, m, source="A", auxiliary="B", target="C"):
    """返回最优方案的第 m 步，不生成前面的移动记录。"""
    if n < 1:
        raise ValueError("n 必须是正整数")
    if not 1 <= m <= 2 ** n - 1:
        raise ValueError("m 必须在 1 到 2 ** n - 1 之间")

    def locate(size, step, source, auxiliary, target):
        middle = 2 ** (size - 1)

        if step == middle:
            return size, source, target
        if step < middle:
            return locate(size - 1, step, source, target, auxiliary)
        return locate(size - 1, step - middle, auxiliary, source, target)

    return locate(n, m, source, auxiliary, target)


n, m = 3, 4
disk, source, target = hanoi_kth_move(n, m)
print(f"第{m}步：圆盘{disk}，{source} → {target}")
print("总移动次数：", 2 ** n - 1)
```

输出：

```text
第4步：圆盘3，A → C
总移动次数： 7
```

`locate` 的三个柱子参数必须随子任务交换。进入右子任务时，还必须把步骤编号减去 `middle`，使它变成右子任务中从1开始的编号。

## 算法执行过程

### 三个圆盘的逐步移动

下表中的列表按“从底部到顶部”的顺序表示圆盘。`[]` 表示空柱，`[3, 2, 1]` 表示3号在底部、1号在顶部。

| 步骤 | 当前移动 | A柱 | B柱 | C柱 |
| --- | --- | --- | --- | --- |
| 初始 | — | [3, 2, 1] | [] | [] |
| 1 | 圆盘1：A → C | [3, 2] | [] | [1] |
| 2 | 圆盘2：A → B | [3] | [2] | [1] |
| 3 | 圆盘1：C → B | [3] | [2, 1] | [] |
| 4 | 圆盘3：A → C | [] | [2, 1] | [3] |
| 5 | 圆盘1：B → A | [1] | [2] | [3] |
| 6 | 圆盘2：B → C | [1] | [] | [3, 2] |
| 7 | 圆盘1：A → C | [] | [] | [3, 2, 1] |

前3步完成第一次递归任务，第4步移动最大圆盘，后3步完成第二次递归任务。可以逐行核对：移动的圆盘始终在源柱顶部，目标柱为空或顶部圆盘比它更大。

### 递归调用与返回

以3个圆盘为例，执行结构如下：

```text
hanoi(3, A, B, C)
├─ hanoi(2, A, C, B)
│  ├─ hanoi(1, A, B, C)  输出圆盘1：A → C，返回1
│  ├─ 移动圆盘2          输出圆盘2：A → B
│  └─ hanoi(1, C, A, B)  输出圆盘1：C → B，返回1
│  返回 1 + 1 + 1 = 3
├─ 移动圆盘3             输出圆盘3：A → C
└─ hanoi(2, B, A, C)
   ├─ hanoi(1, B, C, A)  输出圆盘1：B → A，返回1
   ├─ 移动圆盘2          输出圆盘2：B → C
   └─ hanoi(1, A, B, C)  输出圆盘1：A → C，返回1
   返回 1 + 1 + 1 = 3
整体返回 3 + 1 + 3 = 7
```

树中的“移动圆盘”是当前函数内部的一次操作，不是一次额外调用。左子任务全部完成并返回后，当前层才移动最大圆盘，再进入右子任务。

### 指定步骤查询的执行过程

查询 $n=3,m=5$ 时：

| 当前子任务 | 中间步骤 | 判断 | 下一步 |
| --- | ---: | --- | --- |
| `locate(3, 5, A, B, C)` | 4 | $5>4$，位于右子任务 | `locate(2, 1, B, A, C)` |
| `locate(2, 1, B, A, C)` | 2 | $1<2$，位于左子任务 | `locate(1, 1, B, C, A)` |
| `locate(1, 1, B, C, A)` | 1 | 命中中间步骤 | 圆盘1：B → A |

查询过程中没有执行第1到第4步，只通过判断步骤所在的区间缩小问题，结果与完整移动表的第5行一致。

## 复杂度分析

采用课程常用的基本操作计数模型，把一次整数运算或输出一条移动记录按常数工作量计数，辅助空间按变量和栈帧数量计算。

### 输出完整移动过程

每个非终止调用包含两次规模为 $n-1$ 的调用和常数次额外操作：

$$
T(n)=2T(n-1)+O(1),\qquad T(1)=O(1).
$$

调用树的各层有 $1,2,4,\ldots,2^{n-1}$ 个调用，总调用数为 $2^n-1$，时间复杂度为 $O(2^n)$。仅输出全部移动记录就需要指数数量的操作。

同一时刻等待返回的调用只沿一条路径展开，最长为 $n$ 层，所以辅助空间复杂度为 $O(n)$。两次递归顺序执行，不能把整棵树的节点数当成栈深度。如果额外用列表保存所有移动记录，还需要 $O(2^n)$ 的存储；本文实现逐条输出，不保存全部记录。

### 直接查询指定步骤

每层最多进入一个子任务，圆盘数减1，最多执行 $n$ 层，因此在上述计数模型下，时间复杂度为 $O(n)$，辅助空间复杂度为 $O(n)$。

| 任务 | 时间复杂度 | 辅助空间复杂度 | 是否执行完整移动过程 |
| --- | --- | --- | --- |
| 递归输出全部步骤 | $O(2^n)$ | $O(n)$ | 是 |
| 递归定位第 $m$ 步 | $O(n)$ | $O(n)$ | 否 |

如果只求最少步数，可以直接计算 `2 ** n - 1`，不必生成移动过程。Python 整数可任意增长，这个结果的二进制表示有 $n$ 位；严格按位运算和位存储计费时，大整数运算不能一直视为常数。本节没有进一步按整数位数或输出字符串长度计费。

## 易错点

| 易错点 | 正确理解 |
| --- | --- |
| 把输入条件写成 $n>1$，忽略单盘情况 | $n=1$ 是合法输入，也是递归终止条件 |
| 两次递归使用相同的柱子顺序 | 第一次交换辅助柱和目标柱，第二次交换源柱和辅助柱 |
| 先移动最大的圆盘 | 必须先完成第一次递归，把上面的圆盘移开 |
| 圆盘编号与步骤编号混用 | 圆盘编号表示大小；步骤编号表示移动发生的先后 |
| 将总步数误写为 $2n-1$ | 正确表达式是 $2^n-1$，Python 写作 `2 ** n - 1` |
| 查询右子任务时不调整 $m$ | 进入右子任务时，需要减去 `middle` |
| 用全局计数器但没有重置 | 多次调用可能累积旧结果；本文通过返回值计算步数 |
| 把全部调用数量当作同时占用的空间 | 总调用数是指数级，最大递归栈深度只有 $n$ |

Python 的递归深度受运行环境限制。完整移动过程往往在达到深度限制之前，输出量就已非常大；例如20个圆盘要移动1048575次。演示和手算应优先选择较小的圆盘数，指定步骤查询也需要注意递归深度和大整数成本。

## 课堂练习

1. 手写 $n=2$ 的完整移动过程，说明为什么只需要3步。
2. 当 $n=4$ 时，总移动次数、函数调用总数和最大调用深度分别是多少？
3. 求 $n=4,m=8$ 和 $n=3,m=5$ 对应的移动，分别使用区间定位方法和移动过程核对。
4. 第一次递归为什么写成 `hanoi(n - 1, source, target, auxiliary)`？这里哪一根柱子才是目标柱？

::: details 参考答案
1. 圆盘1：A → B；圆盘2：A → C；圆盘1：B → C。必须先移开小盘、再移动大盘、最后移回小盘，共3步。
2. 总移动次数15次；对于本文以 `n == 1` 为终止条件的实现，函数调用总数15次，最大调用深度4层。
3. 第8步移动4号圆盘，从A到C；第5步移动1号圆盘，从B到A。
4. 第一次递归要把上面的圆盘从 `source` 移到 `auxiliary`，原来的 `target` 作为辅助，因此子问题的目标柱是原来的辅助柱。
:::
